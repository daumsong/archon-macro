1. 설치 방법

1. USB 장치를 컴퓨터에 연결합니다.

2. Archon_Setup.exe 파일을 실행합니다.

Windows SmartScreen 경고가 나타날 수 있습니다.
Archon Macro는 정식 코드 서명(EV 인증서)이 적용된 안전한 프로그램입니다.
아래와 같은 화면이 나타나면 "추가 정보"를 클릭한 후 "실행" 버튼을 눌러주세요.
"추가 정보" 클릭 → "실행" (게시자: biniheart)

3. 설치 마법사의 안내에 따라 설치 완료.

4. 바탕화면 Archon Macro 아이콘 실행.

※ 관리자 권한으로 실행됩니다. UAC 팝업에서 '예'를 클릭하세요.

2. 로그인 (필수)

프로그램 첫 실행 시 로그인이 필요합니다. 관리자 승인된 계정만 사용할 수 있습니다.

아이디 / 비밀번호 입력 후 [로그인]

• 5분 내 로그인 10회 실패 시 5분 잠금이 걸립니다 (남은 시간이 카운트다운으로 표시).

• 로그인 ID는 기억 기능이 있어 다음 실행 시 자동으로 채워집니다.

• 승인 상태는 5분마다 자동 재확인되며, 차단 시 즉시 반영됩니다.

쫄법사마우스 좌클릭 자동 반복 + 자동힐 / 자동귀환
자동버프화면 텍스트 인식 → 거래/파티 자동 클릭 + 키순서 발동, 마나 부족 시 타이핑

5. 쫄법사 탭

쫄 캐릭터용 자동 좌클릭 + 자동힐 / 자동귀환.

쫄법사 탭 활성 — 시작 / 중단 / 토글끔 / Esc 표시

기본 사용

1. ● 시작 클릭 → 3초 카운트다운 표시.
2. 카운트다운 중 마우스로 캐릭터 클릭.
3. 0.3초 간격으로 좌클릭 자동 반복.
4. 토글 단축키(기본 Esc)로 일시정지/재개. ■ 중단으로 완전 종료.

전용 슬롯 설정 (자힐/자버프)

쫄법사 탭의 ⚙ 설정으로 진입 — 단축키 탭과 완전히 독립된 슬롯입니다.

쫄법사 단축키 설정 — 모드에 "자동힐" / "자동귀환" 표시

자동힐 / 자동귀환

자동힐 모드: HP가 임계값 미만이면 단축키 없이도 키순서를 자동 발동. 캐릭터가 죽기 전에 즉각 회복.
자동귀환 모드: HP가 임계값 미만이면 자동으로 귀환 시퀀스 발동.

설정 방법
1. 모드를 "자동힐" 또는 "자동귀환"으로 선택
2. HP 임계값(%) 입력 (예: 60% — HP가 60% 미만이면 발동)
3. 키 순서 편집 (예: F6 → F6)
4. 저장 → 메인에서 쫄법사 ● 시작
※ HP 측정은 ATS의 HP 게이지 좌표를 사용합니다 (ATS 인식영역 picker로 지정).

6. 자동버프 탭 (텍스트 인식)

게임 화면을 자동 모니터링해 "아이템 거래를"(거래 요청) 또는 "승낙하시"(파티 초대) 텍스트를 인식하면 미리 설정한 좌표를 클릭하고 키순서를 발동합니다. 두 게임창을 동시에 처리할 수 있습니다.

창별 설정 (1번창 / 2번창)

각 창 이름 버튼을 클릭하면 창별 상세 설정 다이얼로그가 열립니다.

창별 버프 설정 — 마나 임계값, 슬롯, 타이핑 문구/빈도
항목설명
창 이름구분용 이름 (예: 파티어스)
마나 임계값(%)0이면 위 키순서만 사용. 0보다 크면 마나에 따라 위/아래 자동 분기
마나 ≥ 임계값 시 키순서마나 충분 시 발동할 키순서 (다중 슬롯 + 라디오 선택)
마나 < 임계값 시 키순서마나 부족 시 키순서 (예: 회복 동작)
타이핑 문구마나 부족 상태에서 자동 외칠 문구 (예: /파티탈퇴, 마나포션 구해요)
비워두면 타이핑 안 함. 입력 시 자동으로 Enter까지 전송됨.
빈도(초)타이핑 반복 간격 (예: 5.0초마다 1번)

인식영역 / 클릭 좌표 설정

탭의 🎯 인식영역 버튼으로 다이얼로그 진입.

자동버프 인식영역 / 거래·파티 클릭 좌표 picker
자동버프 인식 영역 — 거래/파티 안내 문구가 출력되는 채팅 라인을 감싸도록 지정
지정해야 할 3가지:
1. 인식영역: 거래/파티 다이얼로그가 뜨는 위치 (텍스트 검사 영역)
2. 거래 클릭: "아이템 거래를" 매칭 시 클릭할 [수락] 버튼 위치
3. 파티 클릭: "승낙하시" 매칭 시 클릭할 [수락] 버튼 위치

각 항목 옆 [표기] 버튼을 누르면 게임창 위에 빨간 사각형/십자선이 3초간 표시되어 정확한 위치를 시각 확인할 수 있습니다.

동작 흐름

0.5초마다 1번창 → 2번창 순회. 한 창 처리 완료 후 다음 창으로.
각 창에서 마나 측정 → 임계값 미만이면 아래 키순서 + 타이핑 발동(빈도 제한)
마나 ≥ 임계값이면 인식영역에서 텍스트 검사
"아이템 거래를" 매칭 → 거래 클릭 + 위 키순서 실행
"승낙하시" 매칭 → 파티 클릭 단독 (키순서 없이)

7. ATS보조 탭

HP/MP 실시간 모니터링 + 자동손상수리 + 반자동수리 통합.

● 시작 / ■ 중단 / 🔧 자동손상수리 / 반자동 수리 / ⚙ 설정

⚙ 설정창

좌측: HP/MP 임계값 + 키순서 · 우측: 인식영역 좌표 (좌상단/우하단 picker)
📍 표기 버튼: 각 영역/좌표 우측의 [표기] 버튼을 누르면 게임창에 빨간 사각형(영역) 또는 빨간 십자선(클릭 좌표)으로 3초간 표시됩니다. 의도한 위치에 잘 찍혔는지 시각적으로 확인 가능.
항목설명
HP 임계값(%)HP가 이 값 미만이면 힐 키순서 발동 (단, MP가 MP 임계값 이상일 때만)
HP < 임계값 시 키순서예: F6 (힐 스킬)
MP 임계값(귀환)MP가 이 값 미만이면 즉시 귀환 시퀀스 (최우선)
MP < 임계값 시 귀환 키순서예: 귀환 스크롤
MP 회복 임계값귀환 후 MP가 이 값 이상이면 복귀 키순서 발동
MP 회복 후 키순서다시 사냥터로 가는 동작 (텔레포트 등)
체크 간격(초)HP/MP 검사 주기 (기본 0.50)

● 시작 (HP/MP 자동 사냥 보조)

두 개의 상태로 순환:
HUNTING (사냥 중)
  • MP < 임계값 → 귀환 키순서 → RETURNED 전환
  • MP ≥ 임계값 AND HP < 임계값 → 힐 키순서 매 사이클 발동
RETURNED (귀환 후)
  • MP ≥ 회복 임계값 → MP 회복 후 키순서 → HUNTING 복귀

🔧 자동손상수리

장비 내구도가 떨어지면 자동으로 인벤 열고 숫돌 위치 찾아서 무기에 사용. 5초마다 화면을 검사합니다.

🔧 반자동 수리

버튼을 누른 시점에 1회만 손상 검사 + 수리 진행 (자동 반복 없음).

8. 자동사냥 탭 (AI 몬스터 인식)

🚫 자동사냥 일시중단

등록한 이미지가 게임 화면에 보이면 자동사냥과 버프가 모두 일시정지됩니다. 안 보이면 자동 재개. 검색 영역은 게임창 우상단(인벤토리/창 영역)으로 고정되어 있고, 사용자는 아이콘 캡처만 하면 됩니다.

타이머 만료 시 (선택) 키순서 발동 후 자동 종료
Insert 키: 게임 중 Insert를 눌러 자동사냥을 즉시 ON/OFF 토글할 수 있습니다.
몹을 잘 못 찾을 때: GPU(그래픽카드)가 미장착된 PC일 수 있습니다. 그래픽카드 없는 환경에서는 인식 속도가 매우 느려져 캐릭터가 이동하는 동안 화면 변화를 따라잡지 못합니다. 설정창 상단의 GPU 상태 표시를 확인하세요.

9. ★ 좌표 지정 가이드 (어디에 찍어야 하나)

환경마다 해상도/UI 위치가 다르므로 좌표는 사용자가 직접 지정해야 합니다.
각 picker 옆의 [표기] 버튼을 누르면 게임창 위에 빨간 사각형/십자선이 3초간 떠서 시각 확인 가능합니다.

ATS 설정창에서 인식영역과 클릭 좌표를 지정합니다 (해상도 4K/FHD 자동 분기 저장). 자동사냥의 차단 이미지/버프 영역은 비율 고정 — 캡처만 하면 됩니다.

① HP 게이지 / MP 게이지

좌상단: HP/MP 막대 시작점 (좌측 끝)

우하단: HP/MP 막대 끝점 (우측 끝)

※ 게이지가 100% 채워졌을 때 기준으로 막대 영역을 정확히 감싸야 합니다. 너무 좁으면 측정이 부정확합니다.

② 인벤토리 영역

자동손상수리가 동작할 때 검사하는 인벤토리 전체 영역을 감쌉니다. 인벤 창이 떠 있을 때 모든 슬롯이 들어가도록 넓게 지정하세요.

③ 숫돌 인식영역

인벤토리에서 숫돌(망치)이 위치한 슬롯 영역. 숫돌이 어느 칸에 있을지 모르므로 충분히 넓게 지정하세요.

④ 손상도 인식 + 손상도 체크 무기 좌표

손상도 인식 (좌상단/우하단): 무기 정보창에서 손상도 텍스트 표시 영역.

손상도 체크 무기 좌표 (좌표 선택): 인벤에서 검사/수리할 무기 한 점을 클릭. 매크로가 이 위치를 우클릭하여 손상도 정보창을 띄웁니다.

※ 숫돌과 자동 수리할 무기는 인벤토리에서 같은 라인(같은 행)에 배치되어야 합니다. 라인이 다르면 자동 수리가 정상 동작하지 않습니다.

⑤ 자동버프 인식영역 + 거래/파티 클릭

인식영역 (좌상단/우하단): 거래 요청 / 파티 초대 다이얼로그가 뜨는 영역. 텍스트만 잘 보이면 충분히 좁게.

거래 클릭: "아이템 거래를" 매칭 시 클릭할 [수락] 버튼.

파티 클릭: "승낙하시" 매칭 시 클릭할 [수락] 버튼.

예시 — 거래 안내 문구가 출력되는 채팅 라인을 빨간 박스처럼 감싸도록 지정

10. 키 순서 편집기

슬롯의 [편집] 버튼으로 진입.

각 동작은 번호와 함께 세로로 나열되며, ▲▼ 순서 변경 / X 삭제 / 클릭으로 수정 가능합니다. 동작 사이에 대기 시간(초) 설정 가능.

+ 키/버튼

• 탭: 키 입력 후 즉시 뗌 (일반)

• 누르기 (유지): 키 누른 상태 유지 (예: Shift)

• 떼기: 누르고 있던 키 떼기

+ 좌표클릭

좌클릭 / 우클릭 / 더블클릭 / 이동 — 반투명 화면에서 클릭으로 좌표 캡처 (Shift/Ctrl/Alt 조합 가능).

+ 타이핑

한글/영문/숫자 모두 지원. 한글 입력 시 PC 입력 모드가 한글이어야 합니다.

+ 드래그

시작점 클릭 → 끝점 클릭 → 이동 시간(초) 입력.

11. 클라우드 설정 (백업/공유)

설정창 하단의 ☁ 클라우드 버튼으로 진입. 본인 ID/비밀번호로 DB에 설정을 저장하고 다른 PC에서도 동일한 설정을 불러올 수 있습니다.

버튼동작
신규등록새 ID로 DB에 행 추가
설정저장현재 매크로 설정을 DB에 저장 (덮어쓰기)

※ 클라우드 ID/비밀번호는 로그인과 별개입니다 (개인 백업용).

12. 주의사항

• 설정 변경 후 반드시 '저장' 버튼을 눌러야 적용됩니다.

• 환경마다 해상도/UI가 다르므로 모든 좌표는 직접 지정이 필요합니다. 미지정 시 기본값(4K/FHD 프로파일)이 사용됩니다.

• 자동버프는 대상 창이 화면에 표시되어야 동작합니다 (가려져 있으면 자동으로 앞으로 가져옵니다).

• ATS보조는 1번창에서만 동작합니다.

• 자동버프는 1번/2번 두 창을 모두 처리합니다.

• 한 창 처리 완료 → 다음 창 순서로 순차 처리됩니다 (동시 처리 X).

• HP/MP 게이지가 가려지거나 UI가 변경되면 감지가 부정확해질 수 있습니다.

• ESC를 3초 이상 누르면 전체 매크로(단축키 탭)가 비활성화됩니다.

• Insert 키로 자동사냥을 ON/OFF 토글할 수 있습니다.

• 탭 전환 시 다른 탭의 동작이 자동 중단됩니다 (한 번에 한 탭).

• USB 장치가 연결되어 있어야 키 입력이 게임에 전달됩니다.

• 한글 타이핑 시 PC 입력 모드가 한글이어야 합니다.

• 타이핑 실행 중에는 다른 모든 매크로가 자동 일시정지됩니다.

• 5분 내 로그인 10회 실패 시 5분 잠금이 걸립니다.
