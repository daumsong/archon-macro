Archon 아콘 설정 기본 가이드

자동사냥 · 아이템 관리 · 버프 관리 · 자동버프 · 촤법사 · 자동촤법사 · ATS보조 · 웹 원격 제어 — 각 기능이 언제 쓰이고, 값을 어떻게 넣는지 한 번에 정리했습니다.

1. 시작 전에 알아둘 기초

1-1. 시작과 중지

  • 자동사냥은 메인 화면의 자동사냥 시작 버튼으로 시작합니다.
  • Insert 키로 자동사냥을 켜고 끌 수 있습니다 (프로그램의 자동사냥 탭이 열려 있을 때 동작). 보급/길찾기 진행 중에 누르면 진행 중인 사이클을 중단하고 자동사냥을 새로 시작합니다.
  • 모든 키 입력과 클릭은 실제 키보드·마우스와 동일한 물리 신호로 들어갑니다. 따라서 동작 중에는 게임창이 화면에 보이는 상태여야 합니다.

1-2. 키순서 편집 (모든 "편집" 버튼 공통)

거의 모든 기능은 "키순서"를 발동합니다. 편집 버튼을 누르면 키순서 편집 창이 열립니다.

  • 키 입력 — 키 추가 후 실제 키보드의 키를 누르면 그대로 등록됩니다 (F1~F12, 문자키 등).
  • 키 누름/뗌 분리 — 키를 누른 채 유지해야 할 때 사용합니다. 예: ▼ F12 (누름) → 다른 동작 → ▲ F12 (뗌)
  • 마우스 클릭/우클릭/더블클릭 — 화면에서 원하는 위치를 클릭해 좌표를 등록합니다. 좌표는 게임창 기준 상대좌표로 저장되므로 게임창을 옮겨도 창 안 같은 지점을 클릭합니다.
  • 딜레이 — 각 동작 뒤 대기 시간입니다 (기본 0.2초). 게임 반응이 느린 동작(창 열기 등) 뒤에는 0.5~1초로 늘려 주세요.
  • 항목은 순서 변경·삭제가 가능하며, 저장하면 즉시 반영됩니다.

1-3. 영역 지정과 아이콘 캡처 (공통)

  • 좌상단/우하단 지정 — 버튼을 누른 뒤 화면에서 좌상단 1번, 우하단 1번 클릭하면 사각 영역이 지정됩니다.
  • 아이콘 캡처 — 같은 방식으로 두 점을 클릭하면 그 부분 이미지가 저장됩니다.
  • 영역은 게임창 크기 기준 비율로 저장됩니다 — 게임창 위치·크기가 바뀌어도 같은 상대 위치를 봅니다.
  • 표기 / 검색영역 보기 버튼으로 지정된 영역이 맞는지 오버레이로 확인할 수 있습니다.
모니터 해상도나 게임창 크기를 크게 바꾸면(예: FHD → 4K) 이미지 모양 자체가 달라집니다. 이 경우 아이콘·아이템 이미지를 다시 캡처해 주세요.

1-4. 상단 GPU 상태 표시줄

  • ● GPU 가속 사용 중 (그래픽카드명) — 몬스터 인식이 그래픽카드로 빠르게 동작하는 정상 상태입니다.
  • CPU로 표시되는 경우 — 인식 속도가 느려져 사냥 반응이 늦어질 수 있습니다. 그래픽 드라이버 업데이트와 Windows 업데이트(옛 버전 Windows 10은 최신 버전으로) 후 PC를 재시작해 보세요.

1-5. 저장 / 취소 규칙

  • 설정 창의 항목 중 상당수(사냥 모드 토글, 키순서 편집 등)는 변경 즉시 저장되고, 임계값·좌표 같은 일부 값은 저장 버튼을 눌러야 반영됩니다. 확실하게 하려면 변경 후 저장을 눌러 닫으세요.
  • 버프 관리 · 아이템 관리 · 타이머매크로 같은 하위 관리창에서 바꾼 내용은 그 창에서 즉시 저장됩니다. 설정 창의 취소로는 되돌아가지 않습니다.

2. 자동사냥 설정 화면

자동사냥 설정 화면

2-1. HP / MP 이하 시 발동 키순서

언제 쓰나: 사냥 중 HP나 MP가 떨어졌을 때 물약·회복 스킬을 자동으로 사용합니다.

  • HP: n% — 사냥 중 HP가 n% 미만이 되면 오른쪽 키순서를 발동합니다. 미만인 동안 매 사이클 반복 발동합니다.
  • MP: n% — MP도 같은 방식입니다.
  • 값을 0으로 두면 해당 기능이 꺼집니다. 키순서가 비어 있어도 동작하지 않습니다.

입력 예: HP 75% + 키순서 F1 → F5 = HP가 75% 아래로 내려가면 F1, F5를 순서대로 입력.

"HP 미만일 때만 발동" 토글 — 켜면 우선순위가 바뀝니다: HP가 임계 미만일 때만 발동하며, 이때 MP도 부족하면 그 차례에는 MP 키순서만 발동합니다(마나부터 채움 — HP 키순서는 다음 차례에). MP만 부족하고 HP가 정상이면 아무것도 발동하지 않습니다. 꺼져 있으면(기본) HP·MP 각각 독립적으로 발동합니다.

2-2. 귀환 HP / 귀환 MP + 귀환 시 발동 키순서

언제 쓰나: HP(또는 MP)가 위험 수준까지 떨어졌을 때 귀환 스크롤 등으로 긴급 탈출합니다.

  • 귀환 HP n% / 귀환 MP n% — 둘 중 하나라도 임계 미만으로 떨어지는 순간 1회 귀환 키순서를 발동합니다. 0이면 해당 조건은 사용 안 함.
  • 발동 후에는 HP·MP가 모두 임계 이상으로 회복돼야 다시 발동할 수 있습니다 (저HP 상태에서 연속 발동 방지).
  • 귀환 키순서가 비어 있으면 임계값을 넣어도 동작하지 않습니다.

귀환 후 이어지는 동작:

  • "HP 회복 후 보급"이 체크된 경우 — 귀환 직후 HP 이하 시 발동 키순서를 HP가 임계값 이상이 될 때까지 반복 발동해 체력을 채웁니다.
  • 체크 해제된 경우 — 귀환 키순서만 입력하고 회복 행위는 하지 않습니다. 귀환 키순서에 "다른 키를 누르면 풀리는 버프"를 넣어 쓰는 경우 이 상태로 두세요.
  • "귀환 후 자동 보급" 토글이 켜져 있으면 이어서 보급 사이클(3장)로 진행하고, 꺼져 있으면 그 자리에서 사냥을 계속합니다.

입력 예: 귀환 HP 15% + 키순서 F8 → ▼ F12 (누름) → ▲ F12 (뗌) → F9 → F1

2-3. 자동토글 사용

언제 쓰나: 게임 내 자동사냥/줍기 토글(F4)을 계속 켜진 상태로 유지하고 싶을 때.

  • 체크하면 자동사냥 시작과 함께 F4를 짧은 간격으로 반복 입력합니다. 사냥 중지·보급 진입 시 함께 멈춥니다.
게임 설정에서 F4에 다른 기능을 넣어 두었다면 의도치 않은 입력이 반복되니 체크를 해제하세요.

2-4. 귀환 후 자동 보급 및 사냥터 복귀 후 사냥

언제 쓰나: 물약·소모품이 떨어지면 자동으로 귀환 → 창고 보급 → 사냥터 복귀 → 사냥 재개까지 무인으로 돌리고 싶을 때. 보급 자동화의 마스터 스위치입니다.

  • 켜면: 아이템 소진(아이템 관리에 등록한 아이템이 슬롯에서 사라짐), 몹 미검출(아래 2-6), 귀환 HP/MP 발동 시 보급 사이클이 진행됩니다.
  • 끄면: 아이템이 부족해도 귀환/보급을 하지 않습니다.
보급 사이클의 세부 설정(창고 키순서, 아이템 등록)은 3장 아이템 관리에서 합니다. 그쪽 설정이 안 되어 있으면 보급이 중간에 실패하고 자동사냥이 중단됩니다.

2-5. HP 회복 후 보급 / MP 회복 후 보급

언제 쓰나: 마을에 귀환한 뒤 체력·마나를 어느 정도 채우고 나서 보급을 시작하고 싶을 때.

  • 체크 + 값 입력 — 귀환 후 HP(MP)가 설정 % 이상이 될 때까지 기다렸다가 보급을 시작합니다. 두 체크박스는 기본 해제, 값은 0~100% 범위에 기본 0%입니다.
  • 체크했어도 값이 0%면 대기 없이 바로 진행합니다. 둘 다 체크했다면 HP·MP 조건이 모두 충족될 때까지 기다립니다.
  • 기다리는 동안은 약 1초 간격으로 게이지만 확인하고 키 입력은 하지 않습니다. 대기 시간에 스킬로 직접 채우고 싶으면 아래 2-12 요정회복스킬 사용을 켜세요.
  • 대기에 들어가기 전 최대 1.5초 동안 게이지 값이 안정될 때까지 기다립니다 — 귀환 직후 화면이 넘어가는 중에 읽은 엉뚱한 값으로 판정하지 않기 위한 것으로, 비슷한 값이 연속 두 번 읽히면 바로 대기를 시작합니다.
  • HP 체크박스는 역할이 하나 더 있습니다 — 위 2-2에서 설명한 대로, 귀환 키순서 직후 이하시 발동 키순서(HP)로 체력을 채울지(체크) / 귀환 키만 입력하고 회복 행위를 전부 생략할지(해제)를 결정합니다. 체크한 경우 HP가 2-1의 HP 칸에 적은 % 이상이 될 때까지 그 키순서를 약 0.3초 간격으로 반복 발동하며 최대 30회입니다. HP 칸이 0이면 1회만 발동합니다. 이 반복 회복은 귀환 후 자동 보급 및 사냥터 복귀 후 사냥 토글과 무관하게 귀환 키순서 뒤에 이어집니다.
  • 전제 조건: 회복 대기 구간 자체는 보급 사이클 안에서만 생기므로 귀환 후 자동 보급 및 사냥터 복귀 후 사냥 토글이 켜져 있어야 합니다.
회복 대기에는 상한이 있습니다. 목표에 도달하지 못해도 180초가 지나면 그대로 다음 단계(보급)로 넘어갑니다. 대기 중에는 Insert로 언제든 중단할 수 있습니다.
게이지를 읽지 못하는 상태(게임창이 가려짐·최소화, 게이지 영역이 현재 해상도와 어긋남)가 20회 연속(약 20초) 이어지면 회복 대기를 건너뛰고 보급을 진행합니다. 회복을 아예 기다리지 않는 것처럼 보이면 ATS보조 설정의 HP 게이지·MP 게이지 영역이 제대로 지정돼 있는지 확인하세요.
자연 회복이 느린 캐릭터에 97% 같은 높은 값을 걸면 매번 180초를 꽉 쓰고 넘어가게 됩니다. 실제로 회복되는 수준으로 낮추거나, 아래 2-12로 스킬을 써서 채우는 편이 훨씬 빠릅니다.

2-6. 몹 미검출 시 자동귀환 시간

언제 쓰나: 몬스터가 안 나오는 구석에 끼었거나, 채널에 몹이 말랐을 때 자동으로 보급 사이클을 돌려 사냥을 다시 시작합니다.

  • 설정한 시간(초) 동안 몬스터가 한 마리도 인식되지 않으면 자동귀환(보급) 사이클을 시작합니다. 몹이 보일 때마다 시간은 처음부터 다시 셉니다.
  • 아이템이 부족하지 않으면 창고 단계는 건너뛰고 사냥터 이동 → 길찾기 → 사냥 재개만 수행합니다.
  • 0이면 사용 안 함. 기본 30초.
  • 전제 조건: "귀환 후 자동 보급" 토글이 켜져 있어야 합니다.
몹 수가 적은 사냥터에서는 값을 넉넉히(예: 120초) 잡아야 헛귀환을 줄일 수 있습니다.

2-7. 타이머 (자동 종료)

언제 쓰나: "3시간만 돌리고 꺼져라"처럼 정해진 시간 후 자동으로 사냥을 끝내고 싶을 때.

  • [h]시간 [m]분 — 사냥 시작 후 이 시간이 지나면 자동사냥이 종료됩니다. 둘 다 0이면 무제한.
  • 종료 시 발동 키순서 — 종료 직후 실행할 키순서(예: 안전지대 이동, 로그아웃). 비워 두면 그냥 멈추기만 합니다.

모드 토글은 하나만 켤 수 있습니다 (하나를 켜면 나머지는 자동으로 꺼짐). 모두 끄면 기본 근거리 방식으로 동작합니다.

뉴 원거리 v2 · 제자리 원거리는 같은 몹을 20초(캐릭터 가까이 붙은 몹은 45초) 넘게 공격해도 안 죽으면 나무 등에 가려 안 맞는 것으로 보고 그 몹을 놓은 뒤, 그 자리를 20초 동안 피해 다른 몹을 칩니다. 몹이 겹쳐 있으면 캐릭터가 앞쪽 몹을 치고 있을 수 있어서, 같은 몹을 잡고 있는 동안 마지막 공격 명령 뒤 일정 시간이 지나면 그 몹에 공격 명령을 다시 보냅니다 (제자리 원거리 7초, 뉴 원거리 v2 10초). 그 몹 그림 안에 다른 몹이나 내 캐릭터와 겹치지 않는 곳이 있을 때만, 그곳을 찍어 다시 공격합니다. 이 간격은 고정이라 따로 설정할 필요가 없습니다 (예전 "뉴 원거리 v2 공격 후 대기(초)" 칸은 없어졌습니다).

사망 인정 시간(초)

공격 중이던 몹이 화면에서 이 시간 이상 연속으로 사라져 있으면 "죽었다"고 판정하고 다음 몹으로 넘어갑니다 (기본 1.0초). 너무 짧으면 인식이 잠깐 끊길 때 살아있는 몹을 버리고, 너무 길면 죽은 몹 앞에서 시간을 낭비합니다. 보통 0.5~1.5초 사이를 권장합니다. 뉴 원거리 v2·제자리 원거리에서는 캐릭터 가까이 있는 몹이 캐릭터 그림에 자주 가려지므로, 그런 몹은 이 값이 1초보다 짧아도 1초로 판정합니다.

뉴근거리v2 + 제자리원거리 드래그 범위 (px)

캐릭터 중심 기준 범위(픽셀)입니다. 제자리 원거리는 이 범위 밖 몹을 무시하고, 뉴 근거리 v2는 범위 밖 몹에게 이동해 접근한 뒤 공격합니다. 0 = 무제한. 범위 확인 버튼을 누르면 게임창 위에 현재 범위(상하 반경 기준, 좌우는 1.5배 넓은 타원)가 표시되니, 눈으로 보면서 값을 조정하세요.

게임창 크기를 바꾸면 같은 px라도 게임 안 실제 거리가 달라집니다. 창 크기 변경 후에는 "범위 확인"으로 다시 확인하세요.

나무가림방지

언제 쓰나: 원거리 모드에서 나무·지형에 시야가 가려 같은 자리만 계속 공격하는 상태를 자동으로 탈출합니다. 뉴 원거리 v2·제자리 원거리 모드는 이 설정과 관계없이 위의 "20초 안 죽으면 놓고 그 자리 피하기"로 자동 처리됩니다.

  • 공격 지점이 설정한 시간(초) 동안 거의 움직이지 않으면 "가림"으로 판정 → 게임창 가운데 쪽 랜덤 지점을 클릭해 자리를 옮깁니다.
"나무가림방지 대기 초"는 반드시 몹 하나를 잡는 데 걸리는 시간보다 길게 설정하세요. 더 짧으면 정상적으로 한 몹을 치는 중에도 가림으로 오판해 자리를 옮겨버립니다.

2-10. 타이머매크로

언제 쓰나: "5분마다 이 키", "30분마다 저 키"처럼 여러 키순서를 각자 다른 간격으로 반복하고 싶을 때.

  • 항목마다 이름 / 사용 스위치 / 간격(초) / 키순서를 등록합니다. 여러 개 등록하면 각자 독립적으로 반복되며, 동시에 겹치면 순서대로 발동됩니다.
  • 여기 "타이머매크로 관리"에서는 등록/편집을 하고, 실행은 메인 화면의 타이머매크로 토글로 켜고 끕니다 — 자동사냥 실행 여부와 무관하게 독립적으로 동작합니다.
주기적으로 걸어야 하는 버프는 타이머매크로보다 버프 관리의 타이머 기능(4-4)을 쓰는 게 좋습니다 — 귀환·보급 중에는 시간이 멈추는 등 버프에 맞게 동작합니다.

2-11. 길찾기 — 목표 좌표로 이동 후 자동사냥 시작

언제 쓰나: 마을/텔레포트 지점에서 정확한 사냥 자리까지 자동으로 걸어가게 하고 싶을 때. 보급 복귀 후에도 같은 자리로 돌아갑니다.

동작 원리: 채팅에 위치 확인 명령을 입력해 화면에 표시되는 게임 좌표를 읽고, 목표 좌표 방향으로 화면을 클릭해 이동 → 도착할 때까지 반복합니다.

  • 1차/2차/3차 목표 (좌우/상하) — 게임에서 쓰는 좌표 숫자를 그대로 입력합니다 (화면 픽셀이 아닙니다). 1차 도착 → 2차 → 3차 순서로 진행하며, 0이면 그 차수는 사용 안 함. 마지막 목표 도착 시 사냥을 시작합니다.
  • 도착 판정 거리 (셀) — 목표에서 이 거리 안에 들어오면 도착으로 인정합니다 (기본 10셀).
  • 길찾기 테스트 — 사냥 없이 길찾기만 실행해 경로와 도착 판정을 확인합니다.
  • 발동 시점: ① 길찾기로 시작하는 버튼을 사용할 때 — 좌표까지 이동 후 사냥 시작 ② 보급 사이클에서 사냥터 이동 키순서 후 좌표까지 이동 후 사냥 재개. (일반 "자동사냥 시작"은 길찾기 없이 그 자리에서 바로 사냥합니다.)
좌표를 읽는 화면 하단 텍스트 인식영역이 맞게 지정돼 있어야 합니다 (초기 설치 시 기본값 제공). 도착 판정 거리를 1~2셀처럼 너무 작게 잡으면 미세 오차로 도착 판정이 안 나 맴돌 수 있습니다. "귀환 후 자동 보급"을 쓰는 경우 1차 목표 좌표와 이 인식영역은 필수입니다 — 없으면 보급 후 복귀를 못 해 중단됩니다.

입력 예: 1차 좌우 32952 / 상하 32813 → 2차 좌우 32890 / 상하 32878 — 초입에서 조금 지난 위치를 1차로 설정하고, 코너 혹은 최종 목적지를 2차로 지정합니다.

2-12. 요정회복스킬 사용 — 귀환 후 스킬로 HP/MP 채우기

언제 쓰나: 귀환 후 회복을 앉아서 기다리지 않고 힐·마나회복 스킬로 직접 채워서, 보급과 사냥터 복귀를 최대한 빨리 하고 싶을 때.

위 2-5의 회복 대기 시간을 그냥 흘려보내지 않고, 그동안 여기 등록한 회복 키순서를 직접 눌러 줍니다.

요정회복스킬 사용꺼짐-이 기능의 켜기/끄기

발동 순서 — 매 바퀴 게이지를 다시 재고 나서, 아래 조건을 위에서부터 확인해 맞는 것 하나만 발동합니다.

  • ① HP가 HP 하한선 미만 → HP 회복 키순서(힐)를 먼저 발동합니다.
  • ② MP가 MP 하한선 미만 → MP 회복 키순서를 발동합니다.
  • ③ HP가 HP 회복 후 보급에 적은 목표 % 미만 → HP 회복 키순서로 마무리 힐을 합니다.
  • 각 줄은 해당 키순서가 등록돼 있을 때만 성립합니다. 예를 들어 HP 회복 키순서를 비워 두면 ①·③은 건너뛰고 ②만 동작합니다.
  • 한 바퀴에 스킬 하나만 나가고, 다음 바퀴까지 약 1초 쉽니다. 매 바퀴 시작 때 HP·MP를 다시 측정하므로 필요 없어진 스킬은 더 이상 나가지 않습니다.
  • 키순서 안의 각 키 사이 간격은 키순서 편집에서 지정한 대기시간(기본 0.2초)을 그대로 씁니다. 발동 직전에 게임창을 앞으로 가져옵니다.
  • ③번 마무리 힐은 HP 회복 후 보급이 체크되고 값이 0%보다 클 때만 동작합니다.
  • 끝나는 시점: HP 회복 후 보급·MP 회복 후 보급에 적은 목표와, MP 회복 키순서를 등록했다면 MP 하한선까지 모두 충족되면 즉시 보급으로 넘어갑니다.
가장 주의할 점 — MP 하한선은 끌 수 없습니다.
이 기능을 켜고 MP 회복 키순서를 등록하면, MP 회복 후 보급 체크를 껐어도 MP가 MP 하한선에 닿을 때까지 기다립니다. 게다가 MP 하한선은 1~99%까지만 넣을 수 있어 0(끄기)으로 내릴 수 없습니다.
MP를 기다리게 하고 싶지 않다면 MP 회복 키순서를 비워 두거나(등록하지 않으면 이 조건이 생기지 않습니다) MP 하한선을 충분히 낮추세요. 기본값 95%를 그대로 두면 MP가 95%가 될 때까지 마을에서 계속 회복 스킬을 씁니다.
반대로, 힐만 등록하면 아무것도 안 나갈 수 있습니다.
HP 회복 키순서만 등록하고 HP 회복 후 보급·MP 회복 후 보급을 둘 다 꺼 두면, 기다릴 이유가 하나도 없다고 판단해 곧바로 보급으로 넘어가며 힐이 한 번도 나가지 않습니다. 힐을 쓰게 하려면 HP 회복 후 보급을 체크하고 목표 %를 넣거나, MP 회복 키순서를 등록해 MP 조건으로 대기가 유지되게 하세요.
MP 회복 스킬은 체력을 소모합니다. 마나를 채우는 스킬이 HP를 깎기 때문에, HP가 HP 하한선 아래로 떨어지면 ①번 힐이 MP 회복보다 먼저 끼어들어 체력을 먼저 세웁니다. HP 하한선을 너무 낮게(예: 10%) 잡으면 MP를 채우는 동안 체력이 위험해질 수 있으니 기본 40% 부근을 권합니다.
권장 설정
요정회복스킬 사용 체크 → MP 회복 키순서에 마나회복 스킬 1개 + MP 하한선 95% → HP 회복 키순서에 힐 1개 + HP 하한선 40% → HP 회복 후 보급 체크 + 마무리 목표 HP(예: 90%) 입력.
이러면 "체력 위험하면 힐 → 마나 95%까지 채움 → 힐로 HP 90% 마무리 → 즉시 보급" 순서가 됩니다.
귀환 직후 3초도 회복에 씁니다. 귀환 HP·귀환 MP로 귀환하면 화면이 넘어가는 동안 3초를 쉬어야 하는데, 이 기능이 켜져 있으면 그 3초를 그냥 버리지 않고 회복에 사용합니다 — 게이지가 잡히는 대로(최대 1.5초) 그 안에서 첫 스킬이 나갑니다. 회복이 먼저 끝나도 3초는 채우고 넘어가며, 이 기능이 꺼져 있으면 그 3초는 그냥 대기입니다.
전제 조건
· 귀환 후 자동 보급 및 사냥터 복귀 후 사냥 토글이 켜져 있어야 합니다 (회복 대기는 보급 사이클 안에서만 생깁니다).
· MP 회복 키순서·HP 회복 키순서 중 최소 하나는 등록해야 합니다. 체크만 하고 둘 다 비워 두면 이 기능은 아예 켜지지 않습니다.
· HP·MP를 읽을 수 있어야 하므로 ATS보조 설정의 HP 게이지·MP 게이지 영역이 지정돼 있어야 합니다.
· 이 기능은 이하시 발동 키순서(HP/MP)와 별개입니다 — 여기 등록한 두 키순서만 씁니다.
회복 대기의 상한은 이 기능을 켜도 똑같이 적용됩니다 — 최대 180초, 게이지 측정 실패가 20회 연속이면 건너뜁니다. 이 기능을 켜면 HP·MP 두 게이지를 모두 읽으므로 둘 중 하나만 계속 못 읽혀도 건너뛰게 됩니다. 스킬 발동 중에도 Insert로 즉시 중단할 수 있습니다.

3. 아이템 관리 — 소진 감지와 자동 보급

자동사냥 아이템 관리 화면

3-1. 어떻게 동작하나 — 소진 감지

  • 사냥 중 2초 간격으로, 등록된 각 아이템의 아이템슬롯 영역(게임 화면의 퀵슬롯 등)에 아이템이 남아 있는지 이미지로 확인합니다.
  • 슬롯에서 아이템이 안 보이는 판정(일치 점수가 슬롯 매칭 임계 미만)이 연속 3회 이어지면 "소진"으로 확정합니다 — 이펙트로 화면이 잠깐 가려지는 정도는 걸러집니다.
  • 소진 확정 → 귀환 시 발동 키순서 발동 → 보급 사이클 시작. 이때 부족한(찾을 개수 미만) 아이템이 모두 함께 보급 대상이 됩니다.

진행 중 언제든 Insert로 중단할 수 있습니다. 게임창을 찾지 못하거나, 창고에서 등록 아이템을 끝내 찾지 못하면 자동사냥 전체가 안전하게 중단됩니다.

4. 버프 관리 — 버프 유지 자동화

자동사냥 버프 관리 화면

4-1. 기본 원리 — 아이콘 감지 발동

  • 버프마다 아이콘 이미지(템플릿) + 키순서를 등록합니다.
  • 사냥 중 2초 간격으로 검색영역을 확인해, 아이콘이 보이면 버프가 걸린 것으로 보고 넘어갑니다. 안 보이는 판정이 연속 3회 이어지면 "버프 꺼짐"으로 확정하고 키순서를 발동해 버프를 다시 겁니다 (화면이 잠깐 가려지는 정도는 걸러집니다).
  • 키순서가 발동되는 동안 사냥(공격/이동)은 잠시 멈추고, 끝나면 재개됩니다.

템플릿 2개 등록 — 같은 버프 아이콘이라도 지역 배경에 따라 다르게 보일 수 있습니다. 배경이 다른 곳에서 캡처한 두 번째 이미지를 등록하면, 둘 중 하나라도 인식될 때 "버프 있음"으로 판정합니다. 한 지역에서만 사냥한다면 1개로 충분합니다.

등록 후 매칭 테스트로 현재 점수를 확인하세요. 버프가 걸린 상태에서 임계보다 확실히 높게, 꺼진 상태에서 확실히 낮게 나와야 안정적입니다 (기본 임계 0.50).

4-2. 버프 카드 항목

항목설명
사용 토글 / 이름 / 삭제버프별로 켜고 끌 수 있습니다. 여러 버프는 카드 순서대로 확인합니다.
검색영역 보기이 버프를 찾는 영역을 게임창 위에 표시합니다.
매칭 테스트현재 화면 기준 템플릿1/2의 일치 점수를 즉석 측정합니다.
아이콘 캡처 1 / 2화면에서 두 점을 클릭해 아이콘 이미지를 저장합니다.
임계1 / 임계2 (기본 0.50)이 점수 이상이면 "아이콘 보임"으로 판정합니다.
키순서버프를 다시 걸 때 입력할 키들입니다.

4-3. MP 발동 조건

언제 쓰나: 마나가 부족할 때 버프 시도로 마나를 낭비하지 않도록, 또는 반대로 마나가 남을 때만 걸도록 조건을 답니다.

  • 이상 — 현재 MP가 설정 % 이상일 때만 발동합니다. (예: 47% 이상 → 마나 여유 있을 때만)
  • 이하 — 현재 MP가 설정 % 이하일 때만 발동합니다.
  • MP 측정이 안 되는 상황에서는 조건을 무시하고 발동합니다.

4-4. 타이머 — 시간 기반 발동 아이콘 감지 대신

언제 쓰나: 아이콘 표시가 없거나 인식이 애매한 버프를 정해진 주기로 다시 걸고 싶을 때.

  • 타이머를 켜면 아이콘 감지는 완전히 생략하고, 시간만으로 발동합니다.
  • 주기(초) — 이 시간마다 발동합니다. 버프 지속시간보다 약간 짧게 잡으세요 (예: 지속 6분 버프 → 300~330초).
  • 후발동(기본) — 사냥 시작 후 주기가 지나면 첫 발동. (사냥 시작 직전에 버프를 손으로 걸고 시작하는 경우)
  • 선발동 — 사냥 시작 즉시 첫 발동 → 이후 주기마다.
  • MP 발동 조건과 조합 — 주기가 됐을 때 MP 조건을 확인해, 충족하면 발동하고 다음 주기를 예약합니다. 부족하면 60초 뒤 다시 시도를 충족될 때까지 반복합니다.
  • 귀환~보급~복귀 동안에는 시간이 멈춥니다 — 복귀하면 멈췄던 지점부터 이어서 세므로, 복귀하자마자 불필요하게 발동되지 않습니다.
  • 자동사냥을 새로 시작하면 모든 버프 타이머가 처음부터 다시 시작됩니다.

4-5. 자동사냥 일시중단 (최상단 항목)

언제 쓰나: 인벤토리 창이 열려있는 동안 매크로가 오동작하지 않게 사냥·버프를 통째로 멈추고 싶을 때.

  • 등록한 이미지가 화면에 보이는 동안 사냥과 버프 발동을 모두 일시정지하고, 안 보이게 되면 자동으로 재개합니다. 정지 중 키 입력은 하지 않습니다.
  • 임계값이 높을수록 판정이 엄격해집니다 — 뚜렷한 이미지(버튼 글자 등)를 등록하고 "매칭 테스트"로 점수를 확인해 조정하세요.
화면에 자주 나타나는 흔한 UI 조각을 등록하면 사냥이 수시로 멈춥니다. 반대로 임계가 너무 높으면 인식을 못 해 정지가 안 될 수 있으니 "매칭 테스트"로 점수를 확인하세요.

5. 자동버프 — 파티 초대만 하면 버프 자동

자동버프 탭

5-1. 어떤 기능인가

버프 받을 캐릭터가 버프캐릭터에게 파티 초대만 걸면 끝입니다. 나머지는 전부 자동으로 진행됩니다:

버프 받을 캐릭터가 버프캐릭터에게 파티 초대
버프캐릭터 화면의 요청 문구를 인식 → 자동 수락 클릭
이어서 버프 키순서 발동 (등록해 둔 키들)
마무리 — "/파티탈퇴"를 두 번 입력해 확실하게 파티 탈퇴 → 다음 요청 대기
  • 타입은 무조건 [타입3]을 선택하고 [파티 → 거래 후 키순서] 토글을 켜세요 — 항상 이 설정으로 사용합니다
  • 게임창을 2개까지 등록할 수 있고, 등록된 창을 차례로 확인하며 요청이 온 그 창에서 처리합니다
  • 자동버프 탭의 시작/정지 버튼으로 켜고 끕니다

5-2. 인식영역·클릭 좌표 설정

자동버프 인식영역 설정 — 타입3 선택 + 파티→거래 후 키순서 ON
  • 자동버프 타입은 무조건 [타입3] 선택 + [파티 → 거래 후 키순서] 토글 켜기
  • 게임창을 띄운 상태에서 지정하세요. 좌표·영역은 해상도(4K/FHD)별로 자동 구분 저장됩니다.
  • 등록된 게임창 — 1번창/2번창 확인, [표기]로 어느 창인지 표시, [교체]로 순서 변경
  • 인식영역 (좌상단/우하단 선택) — 파티·거래 요청 문구가 뜨는 줄을 감싸게 지정
  • 파티 클릭 좌표 — "승낙하시겠습니까" 수락 버튼 위치 / 거래 클릭 좌표 — "아이템 거래를…" 수락 버튼 위치

5-3. 키순서·HP/MP 설정 (창별로 등록)

자동버프 탭 상단의 창별 버튼 — 이 버튼을 눌러야 설정 화면에 진입합니다
  • 진입 방법: 자동버프 탭 상단의 창별 버튼을 클릭하면 설정 화면이 열립니다. 처음에는 [1번창] / [2번창]으로 표시되며, 설정에서 이름을 지정하면 그 이름으로 바뀝니다 (예시 화면의 "파티어스", "파티불").
  • 설정 바꾸기: 두 창 버튼 사이의 ⇄ 버튼을 누르면 1번창·2번창 설정(이름·마나 임계값·키순서·문구 전부)이 서로 바뀌고 바로 저장됩니다. 게임창이 하나만 떠 있어도 쓸 수 있어, 한 창으로 다른 쪽 설정을 쓰고 싶을 때 누르면 됩니다. (게임창 순서 자체를 바꾸는 것은 아래 🔄 1번창 ↔ 2번창 교체입니다.)
타입3 설정 — 거래 클릭 후 키순서에 버프+마무리를 등록
  • 거래 클릭 후 키순서 — 파티 수락 후 이어서 발동되는 본체입니다. 버프 키들을 먼저 넣고, 그 뒤에 파티탈퇴를 등록하세요:
    버프 키들 → 타이핑 "/파티탈퇴" (이 항목의 대기를 1초로 설정) → Enter → 다시 타이핑 "/파티탈퇴" (대기 1초) → Enter
    ※ 타이핑 직후 바로 엔터를 치면 입력이 씹혀 파티탈퇴가 안 되는 경우가 있으므로 타이핑 후 1초 대기 → Enter가 필수이고, 그래도 안 되는 경우가 있어 같은 과정을 두 번 반복해야 확실하게 탈퇴됩니다.
  • HP 임계값 / HP < 임계 시 키순서 — 버프캐릭터의 HP가 임계 미만이면 발동 (회복 등)
  • MP 임계값 / MP < 임계 시 키순서 — MP가 임계 미만인 동안 매 사이클 반복 발동 (마나 회복)
  • 우선순위: 파티/거래 처리 > HP 임계 > MP 임계 — 요청 처리가 항상 먼저이고, 요청이 없을 때만 HP → MP 순으로 확인합니다
  • 이 설정들은 창(캐릭터)별로 따로 등록됩니다 — 1번창·2번창 각각 편집하세요
동작 확인이 필요할 때는 사용자 폴더의 archon_imgsearch.log를 보세요 — 인식된 문구, 클릭 좌표, 키순서 실행이 전부 기록됩니다.

6. 쫄법사 — 보조 캐릭터 자동 조작

6-1. 어떤 기능인가

언제 쓰나: 보조 캐릭터(쫄 캐릭터)를 한 PC에서 돌려두고 싶을 때. 마우스 커서를 올려둔 지점을 계속 좌클릭해 주고, 체력이 떨어지면 미리 등록한 키순서로 힐이나 귀환을 대신 해 줍니다.

  • 상태바의 쫄법사 탭에서 사용합니다. 이 탭은 모든 등급에서 보입니다.
  • 기능은 세 가지입니다 — 자동 좌클릭, 자동힐, 자동귀환. 자동힐·자동귀환은 VIP 이상 등급에서만 동작합니다.
  • 쫄법사 탭에서만 쓰는 전용 단축키 슬롯이 따로 있습니다. 단축키 탭의 매크로 목록과는 완전히 별개로 저장됩니다.
모든 클릭·키 입력은 실제 키보드·마우스와 같은 물리 신호로 들어갑니다. 따라서 게임창이 화면에 보이는 상태여야 하고, USB 장치가 연결되어 있어야 합니다(6-11 참고).

6-2. 탭 화면 구성

버튼하는 일
● 시작쫄법사를 시작합니다. 누르면 3초 카운트다운 후 자동 좌클릭이 시작됩니다. 시작한 뒤에는 이 버튼이 눌리지 않는 상태가 됩니다.
■ 중단쫄법사를 완전히 종료합니다. 실행 중이던 쫄법사 전용 슬롯도 함께 정지되고, 눌려 있던 키가 모두 떼어집니다.
토글켬 / 토글끔표시 전용입니다(눌러서 바꾸는 버튼이 아닙니다). 지금 자동 좌클릭이 켜져 있는지를 보여줍니다 — 초록색 토글켬이 켜진 상태입니다.
Alt+Backspace 처럼 키 이름이 적힌 버튼일시정지/재개 단축키입니다. 현재 지정된 키가 버튼에 그대로 표시되며, 클릭하면 다른 키로 바꿀 수 있습니다(6-5 참고).
⚙쫄법사 단축키 설정 창을 엽니다 — 자동힐·자동귀환·전용 단축키를 여기서 만듭니다.
쫄법사 탭에 머무는 동안에는 단축키 탭의 매크로 슬롯이 모두 꺼집니다(탭을 옮길 때 그 탭의 기능이 꺼지는 공통 규칙). 단축키 탭으로 돌아가면 다시 켜집니다. 쫄법사 전용 슬롯은 이와 무관하게 동작합니다.

6-3. 시작하기 — 3초 카운트다운과 커서 위치

언제 쓰나: 쫄 캐릭터를 자리에 세워두고 자동 좌클릭을 걸 때.

  • ● 시작을 누르면 화면 가운데에 “3초후 쫄기능 시작합니다. 캐릭터 위에 마우스 커서를 올려주세요.” 안내가 뜹니다. 안내는 1번창이 있는 모니터에 표시되므로 모니터가 여러 대여도 헷갈리지 않습니다.
  • 3초 동안 클릭하고 싶은 지점(보통 따라갈 캐릭터 위)에 마우스 커서를 올려 둡니다.
  • 3초가 지나면 안내가 사라지고, 게임창이 맨 앞에 있는 상태라면 그 자리에서 곧바로 좌클릭 한 번이 나갑니다. 이후에는 커서가 있는 지점을 계속 좌클릭합니다.
  • 3초가 지난 시점에 게임창이 맨 앞이 아니었다면 첫 클릭만 생략되고, 조건이 맞는 순간부터 클릭이 시작됩니다(6-4 참고).
  • 커서는 그 지점에 그대로 두어야 합니다. 커서를 옮기면 옮긴 지점을 클릭합니다.
쫄법사는 마우스를 움직이지 않습니다. 지금 커서가 있는 자리를 누르기만 합니다. 그래서 시작 후에 마우스를 다른 곳으로 치우면 그 지점이 계속 클릭됩니다.

6-4. 자동 좌클릭이 나가는 조건

클릭은 약 0.1초마다 한 번씩 시도되며, 아래 조건을 모두 만족할 때만 실제로 나갑니다.

  • 게임창이 맨 앞(활성 창)이어야 합니다. 다른 프로그램을 클릭해 게임창이 뒤로 가면 클릭이 멈춥니다.
  • 커서가 게임창 안에 있어야 합니다. 창 밖으로 나가면 멈춥니다(다른 창을 잘못 누르지 않게 하는 안전장치입니다).
  • 여기서 기준이 되는 창은 1번창입니다. 게임을 두 개 띄웠다면 쫄 캐릭터 창이 1번창이어야 클릭이 나갑니다(6-11 참고).
  • 키순서가 실행되는 동안에는 잠시 멈춥니다. 자동힐·자동귀환·전용 슬롯의 키순서가 끝나면 스스로 다시 시작합니다.
  • 자리홀드를 쓰는 중이라면 Shift가 확실히 눌려 있는 순간에만 클릭이 나갑니다(6-6 참고).
  • USB 장치가 연결되어 있어야 합니다. 연결이 빠지면 아무 클릭도 나가지 않습니다.
클릭을 담당하는 동작이 어떤 이유로 멈추면 1초 안에 자동으로 다시 살아납니다. 잠깐 끊긴 것처럼 보여도 ● 시작을 다시 누를 필요는 없습니다.

6-5. 일시정지 / 재개 단축키

언제 쓰나: 쫄법사를 완전히 끄지 않고, 자동 좌클릭만 잠깐 멈추고 싶을 때.

  • 기본 단축키는 Alt+Backspace입니다. 누를 때마다 토글켬 ↔ 토글끔이 번갈아 바뀝니다.
  • 이 단축키는 ● 시작을 눌러 쫄법사가 켜져 있는 동안에만 동작합니다. 대신 켜져 있는 동안에는 어느 탭을 보고 있어도, 어떤 창이 맨 앞이어도 눌립니다.
  • 키를 바꾸려면 탭에 있는 키 이름 버튼을 클릭합니다. 단축키 입력 창이 열리고 0.5초 준비 후 누른 키가 등록됩니다. 조합키(예: Ctrl+1)와 마우스 버튼도 지정할 수 있습니다.
  • 다른 탭으로 이동하면 자동 좌클릭은 정지(토글끔)됩니다. 단축키를 한 번 누르면 다시 켜집니다.
  • 다른 탭에 다녀온 뒤 쫄법사 탭을 다시 열면 토글끔 상태로 보이고 ● 시작이 다시 눌리는 상태가 됩니다. 단축키로 재개하거나 ● 시작을 다시 눌러도 됩니다(다시 누르면 3초 카운트다운부터 시작합니다).
일시정지 상태(토글끔)에서도 자동힐·자동귀환 감시는 계속 돌아갑니다. 감시까지 멈추려면 ■ 중단을 누르세요.

6-6. 클릭과 게임 규칙 — Shift+클릭과 맨클릭

게임의 클릭 규칙은 이렇습니다. 쫄법사를 쓸 때 반드시 알아야 합니다.

  • Shift를 누른 채 좌클릭 — 캐릭터가 제자리에 서서 대상만 지정합니다.
  • Shift 없이 그냥 좌클릭(맨클릭) — 캐릭터가 클릭한 지점으로 걸어갑니다.
쫄법사의 자동 좌클릭은 맨좌클릭입니다. 즉 Shift가 눌려 있지 않으면 쫄 캐릭터는 클릭한 지점으로 이동합니다. 제자리에 세워둔 채 대상만 잡게 하려면 Shift가 눌려 있는 상태여야 합니다.
Shift를 손으로 계속 누르고 있기 어렵기 때문에, Shift를 눌린 상태로 잡아 주는 자리홀드 기능이 있습니다. 자동쫄법사 권한이 있는 계정에서 자동쫄법사를 시작한 뒤, 자동쫄법사 탭(또는 자동사냥 탭)에서 Delete 키로 켭니다. 이미 걸려 있는 자리홀드를 끄는 것은 어느 탭에서든 Delete로 됩니다.
자리홀드가 켜져 있는 동안에는 Shift가 확실히 눌려 있는 순간에만 좌클릭이 나가도록 프로그램이 스스로 막아 줍니다 — 한 발이라도 맨클릭이 새어나가면 쫄이 그 자리로 걸어가 버리기 때문입니다. 그래서 키순서가 잠깐 Shift를 떼는 구간에는 클릭이 보류됩니다.
자리홀드가 켜져 있는 동안에는 Shift가 들어간 매크로 슬롯 단축키(단축키 탭·ATS보조·쫄법사 전용 슬롯)가 무시됩니다. 자리홀드의 Shift와 사용자가 누른 Shift를 구분할 수 없어 오발동을 막기 위한 것입니다. 쫄법사 일시정지 단축키는 이 제한을 받지 않습니다.

6-7. 슬롯 설정 창(⚙) 공통 항목

언제 쓰나: 자동힐·자동귀환·쫄법사 전용 단축키를 만들 때. 쫄법사 탭의 ⚙ 버튼을 누르면 쫄법사 단축키 설정 창이 열립니다. 슬롯은 위에서부터 슬롯 1, 슬롯 2 … 로 표시됩니다.

  • + 추가 — 슬롯을 하나 만듭니다. 새 슬롯은 이름 매크로N, 모드 1회로 시작합니다.
  • 이름 — 슬롯을 구분하기 위한 이름입니다. 쫄법사 탭에는 표시되지 않습니다.
  • 단축키 — 오른쪽 입력 버튼을 누른 뒤 원하는 키를 누르면 등록됩니다(0.5초 준비 후 감지). 자동힐·자동귀환 슬롯은 비워 둡니다.
  • 키 순서 — 편집 버튼으로 실제 동작(키 입력·좌표클릭·타이핑·드래그)을 등록합니다. 동작마다 뒤에 대기 시간이 붙고, 키·좌표클릭 동작은 기본 0.2초로 들어옵니다(0~9999초 범위로 조절). 편집 방법은 1-2와 같습니다.
  • 모드 — 반복 / 홀드 / 1회 / 자동힐 (VIP) / 자동귀환 (VIP) 다섯 가지입니다.
  • HP 임계값(%) — 모드를 자동힐 또는 자동귀환으로 고르면 나타납니다. 범위 0~100%, 기본값 50%.
  • 삭제 — 그 슬롯만 지웁니다.
설정을 바꾼 뒤 반드시 저장을 눌러야 반영됩니다. 저장하지 않고 창을 닫으면 변경이 모두 취소됩니다.
이 창의 단축키 입력 차단 체크는 값만 기록됩니다. 실제로 게임에 키가 전달되지 않게 막는 것은 단축키 탭의 매크로에만 적용됩니다.
창 아래의 ↑ 내보내기 / ↓ 불러오기 / ☁ 클라우드는 쫄법사 슬롯만이 아니라 프로그램 설정 전체를 다룹니다. ↓ 불러오기는 현재 설정을 덮어쓰고 프로그램을 재시작합니다.

6-8. 자동힐 (VIP)

언제 쓰나: 쫄 캐릭터의 체력이 떨어지면 알아서 힐 키순서를 쓰게 하고 싶을 때.

설정 방법

  • ⚙ → + 추가 → 모드를 자동힐 (VIP) 로 선택합니다.
  • HP 임계값(%) 을 정합니다(기본 50%, 범위 0~100%). HP가 이 값 미만으로 떨어지면 발동합니다.
  • 편집으로 힐 키순서를 등록하고 저장을 누릅니다. 키순서가 비어 있으면 발동하지 않습니다.

동작 방식

  • 쫄법사가 켜져 있는 동안 0.2초마다 체력을 확인합니다.
  • 임계값 미만이면 게임창을 앞으로 가져온 뒤 키순서를 실행합니다. 그 동안 자동 좌클릭은 멈추고, 키순서가 끝나면 다시 시작합니다.
  • 회복됐는지는 따지지 않고 키순서를 한 번만 실행합니다. 힐이 끝나고 1초가 지난 뒤에도 아직 임계값 미만이면 또 발동합니다(힐 직후 게이지가 차기 전에 연달아 쓰지 않게).
  • 체력은 1번창 화면의 HP 게이지를 읽어 판단합니다.
HP 게이지 인식영역이 내 화면과 맞는지 먼저 확인하세요. ATS보조 탭 → ⚙ 설정 → ATS보조 설정 창의 인식영역 설정에서 HP 게이지 항목의 테스트 버튼을 눌러 현재 몇 %로 읽히는지 봅니다. 기본 위치가 들어 있지만 게임 UI 배치가 다르면 엉뚱하게 읽힐 수 있고, 그때는 좌상단·우하단으로 게이지 바에 맞춰 다시 지정해야 합니다. 체력을 읽지 못하면 자동힐은 아예 발동하지 않습니다.
2구간 자동힐 — 자동힐 슬롯을 2개 만들면 HP 구간에 따라 다른 힐을 쓸 수 있습니다. 예: 80% 슬롯에 작은 힐, 60% 슬롯에 큰 힐 → HP가 60% 미만이면 큰 힐만, 60~80%면 작은 힐만 나갑니다. 이 구간 구분은 자동쫄법사 권한이 있는 계정에서만 동작하며, 권한이 없으면 임계값 미만인 슬롯이 모두 발동합니다.
등급이 VIP 미만이면 자동힐·자동귀환은 설정 화면에 보이더라도 발동하지 않습니다.

6-9. 자동귀환 (VIP)

언제 쓰나: 힐로 버티기 어려운 수준까지 체력이 떨어지면 마을로 빼내고 싶을 때.

설정 방법

  • ⚙ → + 추가 → 모드를 자동귀환 (VIP) 로 선택합니다.
  • HP 임계값(%) 을 자동힐보다 낮게 정합니다(기본 50%, 범위 0~100%).
  • 편집으로 귀환 키순서(귀환 주문서 사용 등)를 등록하고 저장합니다. 키순서가 비어 있으면 발동하지 않습니다.

동작 방식

  • 자동힐과 같은 0.2초 주기에서 함께 확인하며, 같은 차례에 둘 다 조건이 맞으면 자동힐이 먼저 처리됩니다. 자동귀환은 힐 직후에도 기다리지 않고 바로 확인합니다.
  • HP가 임계값 미만이면 게임창을 앞으로 가져와 귀환 키순서를 실행합니다.
  • 키순서가 한 번 끝나면 체력을 다시 재고, 임계값 이상으로 회복될 때까지 키순서를 반복합니다(회차 사이 0.3초 대기, 안전 제한 최대 30회).
  • 끝나면 쫄법사가 스스로 중단됩니다 — ● 시작 버튼이 다시 눌리는 상태로 돌아옵니다. 마을에 도착한 뒤 아무 동작도 하지 않게 하려는 처리입니다.
  • 한 번 발동하면 1초 동안 다시 발동하지 않습니다.
자동귀환 임계값을 자동힐 임계값보다 높게 두면 힐을 쓸 기회 없이 바로 귀환합니다. 보통 자동힐 임계값 > 자동귀환 임계값 으로 맞춥니다.

6-10. 쫄법사 전용 단축키 슬롯 (반복 / 홀드 / 1회)

언제 쓰나: 쫄 캐릭터에게만 쓰는 버프·물약·주문 키순서를 손으로 편하게 발동하고 싶을 때.

  • 반복 — 단축키를 누르면 키순서를 계속 되풀이합니다. 다시 누르면 멈춥니다.
  • 홀드 — 키순서에 담긴 키 동작을 차례로 눌러 누른 상태로 유지합니다(좌표클릭 등 다른 동작은 이 모드에서 나가지 않습니다). 같은 단축키를 다시 누르면 모두 뗍니다.
  • 1회 — 단축키를 누를 때마다 키순서를 한 번 실행합니다. 실행이 끝나기 전에 다시 누르면 남은 동작이 취소됩니다.
  • 이 슬롯들은 ● 시작으로 쫄법사가 켜져 있는 동안에만 동작합니다. ■ 중단을 누르면 실행 중이던 슬롯도 함께 정지되고 눌린 키가 모두 떼어집니다.
  • Insert, Delete, PrintScreen 은 프로그램이 쓰는 키라 슬롯 단축키로 지정해도 발동하지 않습니다. 다른 키를 쓰세요.
쫄법사 전용 슬롯은 어떤 창이 앞에 있든 단축키가 발동합니다. 게임이 아닌 창(메모장·브라우저 등)을 보고 있을 때 눌러도 키가 그대로 나가 그 창에 입력됩니다. 게임 밖에서 쓰는 키와 겹치지 않게 지정하세요.

6-11. 대상 창과 USB 장치

대상 창

  • 게임창은 프로그램이 3초마다 자동으로 찾아 등록합니다. 따로 지정할 필요가 없고, 프로그램을 먼저 켜고 게임을 나중에 열어도 반영됩니다.
  • 등록은 최대 2개(1번창·2번창)까지입니다.
  • 쫄법사의 자동 좌클릭과 자동힐·자동귀환의 체력 인식은 모두 1번창을 기준으로 합니다.
어느 게임창이 1번창인지 확인하고 바꾸려면 자동버프 탭의 ⚙ 설정 창을 엽니다. 📌 등록된 게임창 항목의 1번창 표기 버튼을 누르면 해당 창에 빨간 박스가 3초간 표시되고, 🔄 1번창 ↔ 2번창 교체 버튼으로 순서를 바꿀 수 있습니다(두 창이 모두 등록되어 있어야 합니다).

USB 장치

  • 쫄법사의 모든 클릭과 키 입력은 USB 장치를 통해 나갑니다. 장치가 연결돼 있지 않으면 자동 좌클릭·자동힐·자동귀환·전용 슬롯이 전부 동작하지 않습니다.
  • 연결되지 않은 상태로 프로그램을 켜면 로그인 직후 “USB 장치가 연결되지 않았습니다” 안내가 표시됩니다. 프로그램이 종료되지는 않습니다.
아무 오류 없이 클릭만 조용히 안 나가는 증상의 가장 흔한 원인이 USB 장치 연결 문제입니다. 다른 USB 포트에 다시 꽂고 프로그램을 재시작해 보세요.

6-12. 자동쫄법사와 같이 쓸 때

언제 쓰나: 주 캐릭터 PC와 쫄 캐릭터 PC를 연동하는 자동쫄법사 기능을 함께 쓸 때(권한이 있는 계정에만 탭이 보입니다).

  • 쫄 PC에서 자동쫄법사를 쫄(수신) 역할로 시작하면, 쫄법사의 자동 좌클릭이 같이 켜집니다 — 쫄법사 탭에서 ● 시작을 따로 누를 필요가 없습니다. 이때 3초 안내 문구는 표시되지 않지만, 3초 뒤에 시작하는 것은 같습니다(그 사이 커서를 클릭할 지점에 올려 두세요).
  • 자동쫄법사가 동작하는 동안에는 쫄 PC의 자동 좌클릭이 꺼지지 않도록 계속 유지됩니다. 단축키로 껐더라도 곧바로 되살아납니다.
  • 자동쫄법사를 중단하면 쫄법사의 자동 좌클릭도 함께 중단되고, 자리홀드로 눌려 있던 Shift도 풀립니다.
  • 자동쫄법사에서 귀환 신호를 받으면 쫄 PC는 쫄법사의 자동귀환 슬롯에 등록된 키순서를 그대로 실행합니다. 자동귀환 슬롯이 없으면 귀환 없이 자동쫄법사만 종료됩니다.
주(송신) 역할 PC에서는 쫄법사 자동 좌클릭이 켜지지 않습니다. 주 캐릭터가 대신 클릭하게 되는 사고를 막기 위한 것입니다.

6-13. 안 될 때 점검표

증상원인과 해결
클릭이 아예 안 나감USB 장치 미연결이 가장 흔합니다. 그 외 — 게임창이 맨 앞이 아님, 커서가 게임창 밖, 쫄 캐릭터 창이 1번창이 아님.
클릭은 나가는데 쫄이 자꾸 걸어감Shift가 눌려 있지 않은 상태의 맨클릭입니다. 제자리에 세우려면 Shift가 눌려 있어야 합니다 — 자리홀드를 쓰세요(6-6).
다른 탭에 갔다 오니 멈춤정상 동작입니다. 다른 탭으로 옮기면 자동 좌클릭이 토글끔이 됩니다. 일시정지 단축키(기본 Alt+Backspace)를 한 번 누르면 재개됩니다.
탭을 다시 열었더니 ● 시작이 눌리는 상태로 보임다른 탭에 다녀오면 그렇게 보입니다. 감시는 계속 돌고 있으며, 단축키로 재개하거나 ● 시작을 다시 눌러도 됩니다(3초 카운트다운부터 다시 시작).
일시정지 단축키가 안 먹음● 시작을 누른 상태에서만 동작합니다. ■ 중단 상태에서는 반응하지 않습니다. 버튼에 표시된 키가 지금 누르는 키와 같은지도 확인하세요(조합키는 수식키를 함께 누르고 있어야 합니다).
자동힐이 발동하지 않음① 등급이 VIP 미만 ② 체력을 읽지 못함(HP 게이지 인식영역이 내 화면과 안 맞음) ③ 모드가 자동힐 (VIP) 이 아님 ④ 키순서가 비어 있음 ⑤ 설정 후 저장을 누르지 않음.
체력이 낮은데도 반응이 없음ATS보조 탭 → ⚙ 설정 → HP 게이지의 테스트로 현재 몇 %로 읽히는지 확인하세요. 값이 실제 체력과 다르면 좌상단·우하단으로 게이지 바에 맞춰 다시 지정해야 합니다.
자동힐 슬롯 2개가 동시에 나감구간 구분(2구간 자동힐)은 자동쫄법사 권한 계정에서만 동작합니다. 권한이 없으면 임계값 미만인 슬롯이 모두 발동합니다.
귀환만 계속 반복함귀환 키순서 실행 후에도 체력이 임계값 이상으로 회복되지 않는 경우입니다(최대 30회까지 반복). 임계값을 낮추거나 회복이 확인되는 키순서로 바꾸세요.
귀환 뒤 쫄법사가 꺼져 있음정상 동작입니다. 자동귀환이 끝나면 쫄법사는 스스로 중단됩니다. 다시 쓰려면 ● 시작을 누르세요.
설정이 저장되지 않음설정 창의 저장을 눌러야 반영됩니다. 그냥 닫으면 변경이 취소됩니다.
게임을 안 보고 있는데 키가 눌림쫄법사 전용 슬롯 단축키는 창을 가리지 않고 발동합니다. 다른 프로그램에서 쓰는 키와 겹치지 않게 바꾸세요.
슬롯 단축키가 갑자기 안 먹음자리홀드가 켜져 있고 그 단축키에 Shift가 들어가 있으면 무시됩니다(6-6). Shift가 없는 키로 바꾸세요.

7. 자동쫄법사 — 주 PC와 쫄 PC 연동

7-1. 어떤 기능인가 — 주 PC와 쫄 PC

언제 쓰나: 주 캐릭터를 돌리는 PC와 쫄법사를 올려둔 PC가 따로 있고, 주 캐릭터의 체력이 떨어지면 쫄이 알아서 힐을 넣어 주기를 원할 때.

  • 주 PC는 자기 화면에서 주 캐릭터의 HP를 계속 읽습니다. 설정한 % 아래로 떨어지면 쫄 PC에 힐 신호를 보냅니다.
  • 쫄 PC는 신호를 받으면 미리 등록해 둔 힐 키순서를 발동합니다.
  • 힐 외에도 버프 걸기 · 해독 · 제자리 묶기 · 귀환 · 쫄 화면 보면서 원격 조작까지 주 PC 한 곳에서 다룹니다.
자동쫄법사 탭은 사용 권한이 있는 계정에만 표시됩니다. 탭이 보이지 않으면 권한이 없는 계정입니다.
주 PC에서 HP를 읽는 방식은 ATS보조 탭의 HP 게이지 영역을 그대로 씁니다. 그 영역을 지정하지 않으면 HP가 측정되지 않아 힐 신호가 나가지 않습니다. 쫄 PC도 동작 중에 자기 HP·MP를 주 PC 버프 패널에 보여 주므로, 쫄 PC에서도 같은 영역 지정이 필요합니다.

7-2. 역할 설정과 운영 쌍 (같은 공유기·방화벽)

언제 쓰나: 처음 연결할 때 — 두 PC 중 어느 쪽이 주이고 어느 쪽이 쫄인지 정하는 단계입니다.

  • 탭 상단의 역할 드롭다운에서 한쪽은 주(송신), 다른 쪽은 쫄(수신)로 맞춥니다. 그 외에 주소를 입력할 곳은 없고, 역할만 맞으면 서로를 자동으로 찾습니다.
  • 두 PC는 같은 공유기에 연결되어 있어야 합니다. 서로 다른 공유기, 게스트 Wi-Fi, 장치 격리가 걸린 환경에서는 연결되지 않습니다.
  • 처음 실행할 때 Windows 방화벽이 아콘의 네트워크 사용을 물으면 허용하세요. 차단하면 한쪽 방향만 조용히 막혀 "힐은 오는데 버프는 안 간다" 같은 증상이 됩니다.

운영 쌍 수 — 같은 집에서 두 쌍을 돌릴 때만 건드립니다. ⚙ 설정 맨 위에서 정합니다.

운영 쌍 수내 쌍설명
1쌍 (기본)표시되지 않음기본값. 주 1대 + 쫄 1대 이상을 한 묶음으로 씁니다.
2쌍 (같은 집에서 두 쌍 동시 운영)A쌍 / B쌍같은 공유기에서 두 묶음을 동시에 돌립니다. 신호가 서로 섞이지 않습니다.
2쌍으로 쓸 때는 주와 쫄의 쌍을 반드시 같게 맞추세요. 주는 A쌍, 쫄은 B쌍이면 두 PC가 서로를 아예 못 봅니다. 1쌍으로 되돌릴 때도 양쪽 모두 1쌍 (기본)으로 바꿔야 합니다.
한 쌍 안에서 쫄 PC는 여러 대여도 됩니다. 쫄끼리 쌍을 다르게 할 필요는 없고, 전부 같은 쌍으로 두면 됩니다.

7-3. 주 PC — HP 1단 / 2단 / 3단 임계

언제 쓰나: 체력이 조금 빠졌을 때는 작은 힐, 많이 빠졌을 때는 큰 힐로 구간을 나눠 대응하고 싶을 때. ⚙ 설정의 📡 주(송신) 모드에서 정합니다.

설정기본값범위의미
HP 1단 (%)501~99HP가 이 % 미만이면 작은힐 신호를 보냅니다.
HP 2단 (%)0 (비활성)0~99HP가 이 % 미만이면 큰힐 신호까지 함께 보냅니다.
HP 3단 (%)0 (비활성)0~99HP가 이 % 미만이면 3단 신호까지 함께 보냅니다. 가장 위급한 구간.
  • 1단 > 2단 > 3단 순으로 낮게 넣으세요. 예: 1단 70, 2단 40, 3단 20.
  • 0으로 두면 그 단계는 쓰지 않습니다. 1단만 쓰던 기존 설정은 그대로 두면 됩니다.
  • 체력이 2단 구간까지 내려가면 1단과 2단 신호가 같이 나갑니다. 3단 구간이면 1·2·3단이 같이 나갑니다. 받는 쫄은 자기가 맡은 단계 중 가장 높은 단계 하나만 발동하므로, 쫄이 한 대뿐이면 큰힐이 먼저 나가는 셈입니다.
  • 힐 신호는 보낸 직후 0.2초 동안은 다시 나가지 않습니다(연속 발동으로 힐이 겹치는 것 방지). 체력 확인은 0.1초마다 합니다.
⚙ 설정 맨 위의 쿨다운(초)은 연사 방지용 값으로 기본 1초, 범위 1~60초입니다. 힐이 다시 나가는 최소 간격은 이 값과 별개로 0.2초로 정해져 있어, 이 값을 올려도 힐 반응이 느려지지는 않습니다.
주 PC의 게임창이 다른 창에 가려져 있으면 HP를 제대로 읽지 못합니다. 주 캐릭터 게임창은 항상 화면 앞에 있어야 합니다. 인벤토리 등으로 화면이 덮이는 상황은 ⚙ 설정의 🚫 보이면 버프 일시정지에 그 이미지를 등록해 두면, 그 이미지가 보이는 동안 버프 확인과 독 판정을 건너뛰어 잘못된 판정을 막습니다.

7-4. 쫄 PC — 힐 키순서와 담당 힐

언제 쓰나: 쫄 PC에서 한 번만 해 두는 설정입니다. ⚙ 설정의 💉 쫄(수신) 모드 — 힐 키순서 + 자기 버프 관리에서 합니다.

  • 1단 힐 키순서 (작은힐) · 2단 힐 키순서 (큰힐) · 3단 힐 키순서 — 각각 키순서 편집으로 등록합니다. 등록 전에는 미설정으로 표시됩니다.
  • 담당 힐 — 이 PC가 맡을 단계를 고릅니다. 전체 (기본) / 1단만 (작은힐) / 2단만 (큰힐) / 3단만.
  • 이 PC 이름 — 주 PC 화면에서 이 쫄을 구분하는 이름입니다. 최대 16자, 비우면 PC 이름이 자동으로 쓰입니다. 쫄이 두 대 이상이면 반드시 서로 다르게 넣어 두세요.

키순서를 비워 두면 어떻게 되나 — 비어 있어도 힐이 끊기지 않도록 아래처럼 동작합니다.

상황결과
담당 힐 = 전체 (기본), 3단 임계는 넣었는데 3단 키순서가 비어 있음그 구간에서 등록된 키순서 중 가장 높은 단계가 대신 나갑니다 (2단 큰힐 → 없으면 1단 작은힐).
담당 힐 = 전체 (기본)인데 1·2·3단 전부 비어 있음시작 버튼을 눌러도 "쫄(수신) 모드는 힐 키순서가 필요합니다. ⚙ 설정에서 1단 또는 2단 중 하나 이상 등록하세요." 안내가 뜨고 시작되지 않습니다.
담당 힐 = 3단만인데 3단 키순서가 비어 있음시작되지 않습니다. 상태 표시가 담당 힐 3단(미설정)으로 나옵니다.
담당 힐을 지정했다면 그 단계의 키순서를 반드시 등록하세요. 담당 단계만 보고 판단하므로, 다른 단계에 키순서가 들어 있어도 대신 나가지 않습니다.
쫄이 한 대뿐이라면 담당 힐은 전체 (기본)로 두고 1단·2단만 채워 넣는 구성이 가장 단순합니다.

7-5. 시작과 중단 — Insert / Home / End

언제 쓰나: 게임 화면을 보고 있는 상태에서 손을 떼지 않고 켜고 끌 때.

키동작조건
Insert시작 / 중단 토글. 주·쫄이 함께 시작하고 함께 중단됩니다.자동쫄법사 탭이 열려 있을 때. 주·쫄 어느 PC에서 눌러도 됩니다.
Home시작 + 쫄이 자동도킹 좌표를 1회 클릭합니다.자동쫄법사 탭 + 주 PC + 중단 상태일 때만.
End쫄이 자동귀환 키순서를 발동하고 그 PC의 자동쫄법사를 끕니다. 누른 PC도 함께 중단됩니다.자동쫄법사 탭이 열려 있을 때. 주·쫄 어느 PC에서 눌러도 됩니다.
Delete제자리 홀드 켜기 / 끄기 (7-7 참고).켤 때는 자동쫄법사·자동사냥 탭 + 시작 상태. 끄는 것은 어느 탭에서나 됩니다.
  • 버튼으로도 됩니다 — ● 시작 / ■ 중단. 한쪽에서 중단하면 상대 PC도 같이 중단됩니다.
  • 주 PC에서 시작하면 쫄 PC는 자동으로 자동쫄법사 탭으로 전환되고 함께 시작됩니다. 쫄 PC 앞에 사람이 없어도 됩니다.
  • 쫄 PC는 시작과 동시에 쫄법사 좌클릭도 함께 켜집니다(이미 쫄법사가 돌고 있으면 그대로 씁니다). 시작 3초 뒤 그 순간의 마우스 커서 위치를 좌클릭하므로, 쫄 PC의 커서를 쫄 캐릭터 위에 올려 두세요.
  • 동작 중에는 어느 탭에 있어도 화면 우측 위에 📡 자동쫄법사 주 또는 📡 자동쫄법사 쫄 표시가 뜹니다. 눌러 주면 자동쫄법사 탭으로 돌아갑니다.

Home의 자동도킹 — 쫄이 시작 직후 정해진 한 지점을 눌러 주는 기능입니다. 사냥 시작 위치로 붙이거나 주 캐릭터를 따라 붙일 때 씁니다.

  • 좌표는 쫄 PC의 ⚙ 설정 → 📍 자동도킹좌표에서 지정합니다. 게임창 기준 비율로 저장되므로 해상도나 창 크기가 달라도 같은 지점을 누릅니다.
  • 지정 전에는 미지정으로 표시되며, 미지정이면 Home으로 시작해도 클릭은 생략됩니다.
  • 도킹 클릭 뒤 1초 후부터 좌클릭 루프가 시작됩니다.
  • 쫄이 이미 동작 중이어도 도킹 클릭은 실행됩니다(주에서 Home을 누르려면 주 PC가 중단 상태여야 합니다).
End로 귀환하려면 쫄 PC의 쫄법사 탭에서 자동귀환 슬롯에 키순서를 등록해 두어야 합니다. 등록이 없으면 귀환 없이 자동쫄법사만 꺼집니다.

7-6. 쫄이 여러 대일 때 — 힐 분담

언제 쓰나: 쫄법사 PC를 두 대 이상 붙여 놓고, 같은 힐이 겹쳐 나가는 낭비를 막고 싶을 때.

  • 단계로 나누기 — 각 쫄 PC의 ⚙ 설정 담당 힐을 서로 다르게 둡니다. 예: 쫄A는 1단만 (작은힐), 쫄B는 2단만 (큰힐). 체력이 2단 구간까지 떨어지면 두 쫄이 각각 작은힐·큰힐을 넣습니다.
  • 잠깐 끄기 — 쫄이 두 대 이상 붙으면 주 PC의 버프 패널에 쫄별 줄이 생기고, 그 줄의 힐 ON / 힐 OFF로 그 PC의 힐만 멈출 수 있습니다 (7-9 참고). 끈 상태는 저장되며, 그 쫄이 꺼져 있어도 다시 켤 수 있도록 패널에 줄이 남습니다.
  • 쫄이 두 대 이상 붙으면 주 PC 상태 표시에 쫄 2대처럼 대수가 나오고, 힐을 끈 쫄이 있으면 힐 끔 1대가 함께 표시됩니다.
쫄 PC마다 이 PC 이름을 다르게 넣어 두세요. 이름이 없으면 PC 이름으로 표시되는데, 두 대의 PC 이름이 같으면 패널에서 구분할 수 없습니다.
쫄 목록은 각 쫄이 보내오는 소식으로 유지됩니다. 소식이 40초 넘게 끊긴 쫄은 목록에서 빠지고, 다시 켜면 자동으로 돌아옵니다.

7-7. 제자리 홀드 — Delete

언제 쓰나: 쫄법사가 주 캐릭터를 따라 걸어가지 않고 그 자리에 머물면서 힐만 넣게 하고 싶을 때.

  • Delete를 누르면 쫄 PC가 Shift를 계속 누른 상태로 유지합니다. 이 상태에서는 좌클릭이 "그 자리에서 대상 지정"으로 들어가 캐릭터가 이동하지 않습니다.
  • 다시 Delete를 누르면 풀립니다.
  • 주 PC에서 눌러도 됩니다 — 이때 Shift가 걸리는 쪽은 쫄 PC뿐입니다. 주 캐릭터는 영향을 받지 않아 그대로 이동할 수 있습니다.
  • 자동쫄법사를 중단하면 홀드는 자동으로 풀립니다. 귀환(End)으로 끝날 때도 풀립니다.

키순서와 겹칠 때 — 홀드 중에도 키가 제대로 나가도록 상황에 따라 다르게 처리합니다.

상황Shift 처리
힐 키순서계속 누른 채 발동합니다 (짧아서 자리 이탈 위험이 더 큼).
버프 · 해독 · 이동 키순서잠깐 뗀 뒤 발동하고, 끝나면 다시 누릅니다.
원격 패널의 박스 클릭 · F키, 자동도킹 클릭잠깐 뗀 뒤 실행합니다 (클릭은 "그 지점으로 이동"이 목적이므로).
쫄이 여러 대일 때 Delete는 연결된 쫄 전체에 나갑니다. 한 대만 묶으려면 버프 패널의 쫄별 제자리 버튼을 쓰세요.
홀드를 켜는 것은 자동쫄법사·자동사냥 탭에서 자동쫄법사가 시작된 상태일 때만 되고, 끄는 것은 어느 탭에서나 됩니다. Shift가 눌린 채 남았다고 느껴지면 Delete를 한 번 눌러 주세요.

7-8. 쫄 원격 조작 패널

언제 쓰나: 쫄 PC 앞으로 가지 않고, 주 PC에서 쫄 화면을 보면서 이동시키거나 스킬을 눌러 줄 때. 탭의 🎮 쫄 원격 버튼으로 엽니다.

  • 역할이 주(송신)일 때만 버튼이 보입니다.
  • 자동쫄법사를 시작하기 전에도 쓸 수 있습니다. 쫄 PC는 아콘이 켜져 있기만 하면 됩니다.
  • 패널은 항상 다른 창 위에 뜹니다. 게임을 하면서 그대로 누를 수 있습니다.

화면 미리보기

  • 쫄 게임창을 0.5초마다 한 장씩(초당 2장) 받아 박스에 보여 줍니다. 창 크기는 쫄 게임창 1920×1080 — 박스를 누르면 그 지점을 좌클릭합니다처럼 위에 표시됩니다.
  • 패널을 열어 둔 동안만 전송합니다. 닫으면 곧 멈추고, 신호가 끊겨도 쫄이 6초 뒤 스스로 멈춥니다.
  • 쫄 응답이 오기 전에는 쫄 응답 대기 중… (쫄 PC에서 아콘이 켜져 있어야 합니다)로 표시되고 박스와 F키 버튼이 잠깁니다. 쫄이 게임창을 못 찾으면 이 쫄 PC가 게임창을 찾지 못했습니다 — 쫄 PC의 대상 창 설정을 확인하세요로 알려 줍니다.

박스를 누르면 그 지점 좌클릭

  • 박스 안에서 누른 지점을 쫄 PC가 그대로 좌클릭합니다. 쫄 캐릭터를 그 위치로 걸어가게 할 때 씁니다.
  • 좌표는 창 기준 비율로 전달되므로, 패널 크기를 키우거나 줄여도 같은 지점이 찍힙니다.
  • 제자리 홀드가 걸려 있으면 클릭 직전에 Shift를 잠깐 떼고 누릅니다 (그래야 이동이 됩니다).

F키 버튼

  • 첫 줄에 F1 F2 F3, 그 아래 줄에 F5~F12가 있습니다. 누르면 쫄 PC에서 그 키를 눌러 줍니다.
  • F4는 없습니다 — 자동토글이 쓰는 키라서 빼 두었습니다.

창 크기 조절

  • 창 테두리를 끌면 폭이 바뀌고, 다음에 열 때도 그 크기로 열립니다. 기본 폭은 600이고 320~1600 사이로 조절됩니다.
  • 세로는 쫄 게임창 비율에 맞춰 자동으로 맞춰집니다 (아래 F키 줄이 잘리지 않게).
  • 폭을 키우면 받아오는 화면도 조금 더 선명해집니다 (선명도에는 상한이 있어 무한정 올라가지는 않습니다).
쫄이 두 대 이상이면 패널 위에 쫄 선택 드롭다운이 생깁니다. 전체 쫄로 두면 모든 쫄이 동시에 같은 지점을 클릭합니다 — 한 대만 움직이려면 반드시 이름을 골라 주세요.
쫄 PC가 힐·버프 키순서를 돌리고 있으면 원격 조작은 최대 2초까지 기다렸다가 실행되고, 그래도 안 끝나면 그 입력은 취소됩니다. 키순서 한가운데 끼어들어 스킬이 어긋나는 것을 막기 위한 동작입니다.

7-9. 버프 패널 — 제자리·귀환·쫄 자동버프·독풀기

언제 쓰나: 게임을 하면서 버프를 직접 눌러 주거나, 쫄별로 제자리·귀환·힐을 하나씩 다루고 싶을 때. 자동쫄법사를 시작하면 주 PC에 작은 창(🛡 버프)으로 자동 표시되고, 중단하면 닫힙니다.

  • 닫기 버튼은 없습니다. 창의 빈 곳을 끌어서 위치를 옮길 수 있고, 옮긴 자리는 다음에도 유지됩니다.
  • 오른쪽 아래 모서리의 대각선 줄무늬 손잡이를 끌면 창 크기를 조절할 수 있습니다. 오른쪽 아래로 끌면 커지고 왼쪽 위로 끌면 작아지며, 글자·버튼·간격이 같은 비율로 함께 바뀝니다 (0.8배~3배). 조절한 크기는 다음에도 유지됩니다.
  • 버튼을 눌러 발동하는 것은 버프 관리의 사용 스위치가 꺼져 있어도 항상 됩니다.
  • 각 쫄 줄에는 그 쫄의 HP · MP가 함께 표시됩니다. 쫄 보고가 8초 넘게 끊기면 수치가 사라집니다.

버프 버튼

  • 주캐릭 줄 — 주 PC에 등록한 주캐릭 버프입니다. 누르면 쫄이 주 캐릭터에게 그 버프를 시전합니다.
  • 쫄캐릭 줄(쫄이 두 대 이상이면 쫄 · (이름) 줄) — 그 쫄 PC에 등록된 쫄캐릭 버프입니다. 목록은 쫄 PC에서 받아와 표시되므로, 쫄 PC의 ⚙ 설정 → 🛡 쫄캐릭 버프 관리에서 이름과 키순서까지 등록해야 버튼이 생깁니다.
  • 쫄이 두 대 이상이면 시전: 전체 ▾ 버튼으로 주캐릭 버프를 어느 쫄이 시전할지 고를 수 있습니다 (버튼을 직접 누를 때만 적용됩니다).

쫄 자동버프 전체 스위치

  • 쫄 자동버프 ON / 쫄 자동버프 OFF — 끄면 쫄캐릭 버프가 쫄 PC에서 자동으로 발동하지 않습니다. 개별 버프의 스위치·타이머를 켜 뒀어도 이 스위치가 우선합니다.
  • 주캐릭 버프와 패널의 수동 버튼은 영향을 받지 않습니다.
  • 기본값은 켜짐이며, 바꾸면 쫄 PC들에 바로 전달됩니다.

쫄별 버튼

버튼동작
힐 ON / 힐 OFF그 쫄 PC의 힐만 끄거나 켭니다. 설정에 저장되어 다시 시작해도 유지됩니다. 쫄별 줄이 생기는 구성(쫄 2대 이상, 또는 힐을 끈 쫄이 남아 있을 때)에서 나옵니다.
제자리그 쫄만 제자리에 묶습니다 (Delete와 같은 홀드). 켜지면 제자리 ON으로 바뀝니다. 다시 누르면 풀립니다. 쫄이 한 대여도 있습니다.
귀환그 쫄만 자동귀환 키순서를 발동하고 그 PC의 자동쫄법사를 중단합니다 (End는 연결된 쫄 전체에 나갑니다). 쫄이 한 대여도 있습니다.

독풀기 담당 쫄 — 쫄이 두 대 이상일 때 독풀기: 전체 ▾ 버튼이 나옵니다.

  • 주 캐릭터가 독에 걸렸을 때 해독을 맡을 쫄 한 대를 지정합니다. 설정에 저장됩니다.
  • 전체로 두면 연결된 쫄이 모두 해독해 중복 발동됩니다 — 쫄이 두 대 이상이면 한 대를 지정하는 것이 좋습니다.
  • 지정한 쫄이 꺼져 있으면 독이 반드시 풀리도록 전체가 해독합니다.
주캐릭 버프도 없고 쫄 PC에서 받아온 쫄캐릭 버프 목록도 없으며 쫄이 한 대뿐이고 힐을 끈 쫄도 없으면, 보여 줄 것이 없어 패널이 뜨지 않습니다. 쫄 목록이 도착하면 다시 나타납니다.

7-10. 독(초록 HP) 해독 키순서

언제 쓰나: 독에 걸려 HP 게이지가 초록으로 바뀌었을 때 자동으로 해독하고 싶을 때. 해독은 쫄법사 역할이라 키순서는 모두 쫄 PC의 ⚙ 설정에서 등록합니다.

설정누가 감지누가 발동
주캐릭(독) 키순서주 PC가 주 캐릭터를 봅니다쫄 PC가 이 키순서를 발동합니다
쫄캐릭(독) 키순서쫄 PC가 자기 캐릭터를 봅니다쫄 PC가 스스로 발동합니다
  • 독 시퀀스 쿨다운(초) — 한 번 발동한 뒤 이 시간 동안은 다시 발동하지 않습니다. 기본 10초, 범위 1~600초.
  • 판정 기준은 HP 게이지 영역의 초록색 픽셀이 8% 이상인지입니다. 그래서 ATS보조 탭의 HP 게이지 영역 지정이 필수입니다.
  • 키순서를 등록하지 않았으면 아무 일도 일어나지 않습니다. 쫄캐릭(독) 키순서는 등록해 두어야 감지 자체가 돌아갑니다.
  • 🚫 보이면 버프 일시정지에 등록한 이미지가 화면에 보이는 동안에는 독 판정을 건너뜁니다.
쫄이 두 대 이상이면 주 캐릭터 해독이 두 번 나갈 수 있습니다. 버프 패널의 독풀기에서 담당 쫄을 지정하세요 (7-9 참고).

7-11. 쫄 이동 / 자동토글

언제 쓰나: 쫄법사를 정해진 자리로 옮기거나, 게임 내 토글 키를 켜진 상태로 유지할 때. 둘 다 탭 상단에 있습니다.

🚶 쫄 이동 ▼ 드롭다운 — 역할이 주(송신)일 때만 보입니다.

  • 목록에서 이름을 고르면 쫄 PC에서 그 이동 키순서가 즉시 발동됩니다.
  • 키순서는 쫄 PC의 ⚙ 설정 → 🚶 이동 키순서 관리에서 등록합니다 (클릭 좌표가 쫄 화면 기준이라 쫄에서 등록해야 합니다). 주 PC에는 이름만 떠서, 주에서는 따로 설정할 것이 없습니다.
  • 이름이 보이지 않으면 🔄 목록 새로고침을 고르세요. 쫄 PC의 아콘이 켜져 있어야 목록이 옵니다.

자동토글 스위치 — 기본은 꺼짐입니다.

  • 켜면 자동쫄법사가 동작하는 동안 F4를 0.4초마다 반복 입력합니다. 자동쫄법사를 중단하면 함께 멈춥니다.
  • 게임창이 화면 앞에 있을 때만 입력하며, 채팅 등을 타이핑하는 동안에는 2초 동안 멈춥니다 (한글 자소가 갈라지는 것 방지).
게임 설정에서 F4에 다른 기능을 넣어 두었다면 의도치 않은 입력이 반복되니 스위치를 끄세요.

7-12. 통신이 안 될 때 확인할 것

언제 쓰나: 역할까지 맞췄는데 힐이 안 오거나, 원격 패널이 쫄 응답 대기 중…에서 넘어가지 않을 때.

먼저 ⚙ 설정 → 📡 통신 진단을 양쪽 PC에서 모두 열어 주세요. 서로가 보이면 네트워크는 정상입니다.

  • 표에 상대 PC의 IP · 호스트 이름 · 역할 · 동작 여부 · 마지막 응답 시각이 뜹니다. 5초 안에 응답한 PC만 표시됩니다.
  • 진단은 같은 쌍끼리만 서로를 찾습니다. 아무것도 안 보이면 쌍이 어긋난 것, 같은 공유기가 아닌 것, 방화벽 차단, 공유기의 장치 격리나 게스트 Wi-Fi가 원인입니다.
증상원인과 해결
힐이 전혀 오지 않음역할 중복 — 두 PC 모두 주(송신)이거나 모두 쫄(수신)인 경우. 진단 표의 역할 칸에서 바로 확인됩니다. 한쪽을 반대로 바꾸세요.
서로를 아예 못 봄 (진단 표에도 안 나옴)쌍 불일치 — 운영 쌍 수가 한쪽만 2쌍이거나, 내 쌍이 A/B로 갈린 경우. 양쪽을 같게 맞추세요.
한 방향만 안 됨 (힐은 오는데 버프·원격은 안 감)Windows 방화벽이 한쪽 아콘을 차단한 경우가 많습니다. 방화벽에서 아콘의 네트워크 사용을 허용하세요.
같은 버프·해독이 두 번 발동유선과 무선을 동시에 연결한 PC에서 신호가 두 번 도착하는 경우입니다. 진단 표에 자기 PC 이름이 다른 IP로 한 번 더 보이면 이 경우입니다 — 유선 또는 무선 한쪽만 연결하세요. (쫄이 여러 대일 때의 해독 중복은 버프 패널의 독풀기 담당 지정으로 해결합니다)
가끔 신호를 놓침노트북 무선은 절전 기능으로 신호가 사라질 때가 있습니다. 가능하면 유선으로 연결하고, 전원 옵션에서 무선 절전을 끄세요.
쫄이 목록에서 사라짐쫄 PC의 아콘이 꺼졌거나 신호가 40초 넘게 끊긴 경우입니다. 다시 켜면 자동으로 목록에 돌아옵니다.
진단 화면에 포트가 점유 중 또는 차단으로 표시됨아콘이 두 번 실행되어 있거나 다른 프로그램이 같은 통로를 쓰고 있습니다. 아콘을 완전히 종료한 뒤 하나만 실행하세요.
원격 클릭·F키가 안 먹음쫄 PC의 장치가 연결되지 않은 경우입니다 (모든 입력은 실제 장치로 나갑니다). 쫄 PC의 장치 연결 상태를 확인하세요.
쫄 화면이 안 보임쫄 PC가 게임창을 못 찾는 경우 — 쫄 PC의 대상 창 설정을 확인하세요. 패널이 그 사실을 문구로 알려 줍니다.
주 PC에서 시작하면 쫄 PC는 알아서 자동쫄법사 탭으로 전환되며 시작됩니다. 쫄 PC가 다른 탭에 있어도 시작 신호는 받습니다 — 단, 쫄 PC에서 Insert · End를 직접 누르려면 그 PC가 자동쫄법사 탭에 있어야 합니다.

8. ATS보조 — HP/MP 감시와 수리·아이템 점검

8-1. 무엇을 하는 탭인가 · 시작 전 준비

언제 쓰나: 몬스터를 직접 잡을 필요는 없고, HP·MP만 지켜보다가 힐·귀환·마을 회복·사냥터 복귀를 알아서 하게 하고 싶을 때. 무기 수리나 소모품 칸 점검만 따로 돌리고 싶을 때도 이 탭을 씁니다.

상단 상태바에서 ATS보조 탭을 누르면 버튼들이 한 줄로 나옵니다. 이 탭 자체는 권한과 무관하게 항상 보입니다.

버튼하는 일● 시작과의 관계
● 시작HP/MP 감시 + 버프 유지 + 타이머 + 아이템체크를 한꺼번에 시작—
■ 중단모두 즉시 중지—
🔧 자동손상수리5초마다 인벤을 검사해 손상 무기를 계속 수리따로 동작
반자동 수리수리 절차를 딱 1회만 실행하고 스스로 꺼짐따로 동작

● 시작은 자동사냥 이용자만 쓸 수 있습니다. 권한이 없으면 ● 시작 버튼이 눌리지 않고, 버튼에 "ATS보조 시작 기능은 자동사냥 이용자만 사용할 수 있습니다."라는 안내만 나옵니다. 다만 ⚙ 설정의 인식영역 지정과 테스트는 누구나 할 수 있습니다(다른 탭 기능들이 이 영역을 함께 쓰기 때문입니다).
  • 감시 대상은 1번 게임창 하나입니다. 등록된 게임창 중 첫 번째 창의 HP/MP만 봅니다. 게임창이 등록되지 않았거나 닫혀 있으면 아무 동작도 하지 않습니다.
  • 자동사냥과 동시에 돌 수 없습니다. ATS보조를 시작하면 진행 중이던 자동사냥·보급·길찾기가 먼저 자동 중단되고, 반대로 자동사냥을 시작하면 ATS보조가 자동 중단됩니다.
  • 키순서를 발동할 때마다 게임창을 맨 앞으로 올린 뒤 입력합니다. 키·클릭은 실제 키보드·마우스와 같은 신호로 들어가므로 게임창이 화면에 보이는 상태여야 합니다.
  • ATS보조는 사냥중 단계와 마을 단계를 번갈아 갑니다. 어떤 동작이 발동될지가 이 단계로 갈리지만, 지금 어느 단계인지는 화면에 표시되지 않습니다.
Insert 키는 ATS보조를 켜거나 끄지 않습니다(자동사냥 탭 / 자동쫄법사 탭 전용). ATS보조는 반드시 ■ 중단 버튼으로 멈춰야 합니다.

8-2. ● 시작 / ■ 중단

언제 쓰나: 설정을 다 넣은 뒤 감시를 켜고 끌 때.

  • ● 시작을 누르면 사냥중 단계로 시작하고, 아래 4가지가 동시에 각각 돌기 시작합니다.
    • HP/MP 감시 (힐 → 귀환 → 회복 대기 → 복귀)
    • 버프 유지 (8-11)
    • 타이머 키순서 (8-10)
    • 아이템체크 (8-12)
  • ■ 중단을 누르면 즉시 멈추고, 진행 중이던 동작을 정리한 뒤 누르고 있던 키를 모두 뗍니다.
원격(텔레그램·웹)으로도 ATS보조 시작/중단이 됩니다. 이때도 자동사냥 권한이 필요하며, 시작하면 "ATS보조 시작 (자동사냥은 함께 중단됨)" 안내가 옵니다.
수리 버튼 2개는 ● 시작과 완전히 별개입니다. ATS보조를 시작하지 않고 수리만 돌릴 수도 있고, 시작 중에 같이 켤 수도 있습니다.

8-3. ⚙ 설정 — HP/MP 게이지 인식영역

언제 쓰나: ATS보조를 처음 쓰기 전에 제일 먼저 해야 하는 작업입니다. 이 영역이 어긋나면 힐·귀환이 전혀 안 걸리거나 엉뚱하게 걸립니다.

⚙ 설정 창 오른쪽 📍 인식영역 설정에서 지정합니다.

영역은 게임창 크기 대비 비율로 저장되어, 창 크기를 바꿔도 따라갑니다. 지정하지 않으면 기본값으로 동작하지만, 화면 구성이 사람마다 달라 직접 지정을 권장합니다.
저장 규칙이 항목마다 다릅니다. 영역·좌표를 클릭해 찍을 때, restart 이미지 · restart v2 이미지를 캡처할 때, restart v2의 사용 스위치를 켜고 끌 때는 즉시 저장됩니다(그때 화면에 떠 있던 임계값·스위치까지 함께 저장됩니다). 임계값·스위치·키순서만 고쳤을 때는 저장을 눌러야 적용됩니다. 🎯 버프 관리 · 🔍 아이템체크 · ⏱ 타이머 키순서는 별도 창이라 고치는 즉시 저장됩니다.
HP·MP 확인 간격은 화면에 없는 고정값입니다. 설정을 한 번이라도 저장한 뒤에는 0.3초, 한 번도 저장하지 않았다면 0.5초입니다.

8-4. HP 임계값 + 키순서 (힐)

언제 쓰나: HP가 떨어지면 물약·힐 스킬을 자동으로 쓰게 할 때.

항목기본값범위설명
HP 임계값50%0~100%HP가 이 값 미만이면 아래 키순서 발동
HP < 임계값 시 키순서미설정—물약 먹기 / 힐 스킬 등
  • 사냥중 단계에서만 발동합니다. 마을 단계에서는 발동하지 않습니다.
  • 조건만 맞으면 확인할 때마다(0.3초) 반복 발동합니다. 쉬는 시간(쿨다운)이 없습니다.
  • 키순서가 비어 있으면 아무 일도 일어나지 않습니다. HP 인식에 실패한 회차도 발동하지 않습니다.
HP 임계값 칸의 안내 문구에는 MP 조건이 함께 적혀 있지만, 실제 힐은 MP와 무관하게 발동합니다.
임계값을 높게(예: 90%) 잡으면 조건이 계속 참이라 키순서가 끊임없이 발동해 물약이 순식간에 소모됩니다. 실제로 위험한 선으로 잡으세요.

8-5. 귀환 3종 — MP만 / HP만 / HP·MP 통합

언제 쓰나: 물약이나 마나가 바닥나면 마을로 빠져나가 채우고 다시 사냥터로 돌아오게 하고 싶을 때.

귀환 방식은 3가지입니다. 각 방식은 귀환 임계값 + 귀환 키순서 + 회복 대기 값 + 회복 후 키순서를 한 묶음으로 가집니다.

방식스위치기본귀환 조건임계값 기본
MP만MP 관련 기능 사용켜짐MP가 MP 임계값(귀환) 미만30%
HP만HP 임계값 이하 귀환 사용꺼짐HP가 HP 임계값(귀환) 미만30%
통합HP·MP 통합 귀환 사용꺼짐HP 또는 MP 하나라도 미만HP 30% / MP 30%

모든 임계값은 0~100%입니다. 귀환 키순서 칸 이름은 각각 MP < 임계값 시 귀환 키순서 · HP < 임계값 시 귀환 키순서 · HP/MP < 임계값 시 귀환 키순서이며, 보통 귀환 스크롤이나 마을 이동 스킬을 넣습니다.

우선순위 — HP·MP 통합 귀환 사용을 켜면 개별 HP 귀환·MP 귀환은 무시됩니다(중복 귀환 방지). 같은 차례에서 검사 순서는 힐 → 통합 귀환 → HP 귀환 → MP 귀환입니다. 단, HP가 귀환 임계값 아래면 힐을 건너뛰고 바로 귀환합니다(귀환이 먼저).
스위치를 켰어도 귀환 키순서가 비어 있으면 귀환하지 않습니다. 임계값만 넣고 키순서를 비워 두는 실수가 가장 많습니다.
  • MP 귀환에는 별도 스위치가 없습니다. MP 관련 기능 사용이 켜져 있고 MP 귀환 키순서가 들어 있으면 동작합니다.
  • MP 관련 기능 사용을 끄면 MP 임계값(귀환) · MP 귀환 키순서 · MP 회복 대기 · MP 회복 후 키순서 칸이 모두 비활성화되고, MP 때문에 귀환하는 동작이 전부 사라집니다. HP 힐은 계속 작동합니다.
  • 귀환 키순서를 끝까지 발동한 시점에 마을 단계로 넘어갑니다. 마을에 실제로 도착했는지는 확인하지 않습니다(버땅에서만 8-8로 확인 가능).
  • 단계가 바뀐 직후 1초는 다음 단계 전환을 하지 않습니다(연속 오발동 방지). 힐에는 이 대기가 적용되지 않습니다. 사냥터에 막 도착한 직후에는 이 대기 대신 8-7의 빠른 HP 감시가 지킵니다.

8-6. 귀환 후 회복 대기와 사냥터 복귀

언제 쓰나: 마을에 도착한 뒤 체력·마나가 어느 정도 찰 때까지 기다리고, 그 다음 자동으로 사냥터로 돌아가게 하고 싶을 때.

마을 단계에서는 어떤 사유로 귀환했는지에 따라 기다리는 조건이 달라집니다.

귀환 사유복귀 조건기본값발동 키순서
MP 귀환MP가 MP 회복 대기 이상80%MP 회복 후 키순서
HP 귀환HP가 HP 회복 대기 이상80%HP 회복 후 키순서
통합 귀환통합 복귀 — HP 회복 대기 이상 그리고 통합 복귀 — MP 회복 대기 이상각 80%HP·MP 회복 후 키순서
  • 모든 회복 대기 값의 범위는 0~100%입니다.
  • 회복 대기는 목표에 도달할 때까지 계속 기다립니다. 자연 회복이 느린 캐릭터에 97% 같은 높은 값을 걸면 아주 오래 서 있게 됩니다.
  • 조건이 차면 회복 후 키순서(보통 텔레포트 · 사냥터 이동)를 발동하고, 끝나면 다시 사냥중 단계로 돌아옵니다.
  • 회복 후 키순서가 돌아가는 동안에는 버프 유지가 끼어들지 않습니다(키가 섞이지 않게 잠시 멈춤).
회복 후 키순서 템플릿 — 세 줄(MP / HP / HP·MP 회복 후 키순서)마다 [편집] [복붙] 옆에 📋 템플릿 드롭다운이 있습니다. ＋ 지금 키순서를 템플릿으로 저장으로 이름(예: 기란 사냥터)을 붙여 두면, 세 줄 어디서든 그 이름을 골라 키순서를 바로 넣을 수 있습니다(고르는 즉시 저장). 필요 없어진 템플릿은 ✕ 템플릿 삭제로 지웁니다.
가장 위험한 함정 — 켜 둔 귀환 방식의 회복 후 키순서가 비어 있으면 마을 단계에서 영원히 빠져나오지 못합니다. 이 단계에서는 힐도 발동하지 않습니다(힐은 사냥중 단계 전용). 귀환 키순서를 넣었다면 회복 후 키순서도 반드시 넣으세요.
MP 관련 기능 사용을 끈 경우, MP 때문에 마을 단계로 들어가 있던 캐릭터는 자동으로 사냥중 단계로 되돌려집니다(마을에 갇히지 않게). 단 HP 귀환·통합 귀환으로 들어온 마을 단계는 정상적으로 회복을 기다립니다.

8-7. 복귀 이동 중 HP가 또 떨어지면 — 재귀환

언제 쓰나: 마을에서 사냥터로 돌아가는 도중, 또는 막 도착한 순간에 다시 맞아서 위험해질 때. 따로 켤 설정이 없습니다 — 귀환 키순서가 하나라도 있으면 저절로 동작합니다. 원칙은 "HP가 귀환 임계값 아래면 무엇보다 귀환이 먼저"입니다.

  • 사냥터로 가는 동안은 회복 후 키순서를 누르는 도중, 버땅 확인을 기다리는 동안, 그리고 키순서가 끝난 뒤 도착 직후 3초까지입니다.
  • 이 동안 HP를 0.1초마다 확인합니다. HP가 귀환 임계값 미만으로 0.45초 넘게 계속 읽히면 남은 이동 키를 버리고 곧바로 귀환 키순서를 발동합니다. HP가 떨어진 뒤 귀환 첫 키까지 약 0.5~0.6초입니다.
  • 0.45초를 기다리는 이유: 텔레포트 목록창 같은 게임 안의 창이 HP 바를 잠깐 가리면 HP가 낮게 잘못 읽힙니다. 그 정도로는 귀환하지 않게 하는 안전장치입니다.
  • 재귀환 후에는 평소처럼 회복 대기 → 회복 후 키순서 → 사냥터 복귀를 다시 거칩니다.
  • 도착 직후 3초 동안은 텔레포트를 쉬고, 버프·아이템체크도 끼어들지 않습니다. 힐은 나가지만, HP가 귀환 임계값 아래로 확인되는 중이면 힐보다 귀환이 먼저입니다.
기준값은 새 설정이 아니라 8-5의 임계값을 그대로 씁니다. 통합 귀환이 켜져 있으면 통합 귀환 — HP 임계값, 아니면 HP 임계값(귀환)입니다. MP는 로딩 화면에서 0%로 잘못 읽히는 일이 잦아서, 이동 중에는 예전처럼 0.4초마다 재서 연속 2회 낮을 때만 귀환합니다.
HP 귀환을 꺼 둔 분도 보호됩니다. 사냥터로 가는 동안에는 HP 임계값 이하 귀환 사용이 꺼져 있어도, HP가 HP 임계값(귀환) 아래면 귀환합니다. HP 귀환 키순서가 있으면 그것을, 없으면 MP 귀환 키순서를 씁니다. 이렇게 돌아오면 마을에서 HP가 HP 회복 대기 값까지 찬 뒤에 출발합니다. 마을에서 HP가 귀환 임계값 아래면 [실행] 버튼도 거절됩니다. 평소 사냥 중에는 스위치 설정을 그대로 따릅니다.
평소 사냥 중에도 HP가 귀환 임계값 아래로 떨어지면 힐을 건너뛰고 바로 귀환합니다(예전에는 힐 키순서를 다 누른 뒤 귀환해서 그만큼 늦었습니다).
사냥터에 도착하지 못하고 연속 5번 다시 귀환하면 자동 복귀를 멈추고 마을에서 대기합니다(귀환 주문서를 끝없이 쓰는 것을 막기 위해). 트레이 알림이 뜨면 HP 게이지 인식영역과 사냥터를 확인한 뒤, ATS보조 설정창의 회복 후 키순서 옆 [실행]을 눌러 다시 출발하세요. ATS보조를 껐다 켜면 '사냥중'으로 시작하므로 마을에서는 출발하지 않습니다.
로딩 화면처럼 어두운 화면에서는 HP가 100%로 읽혀서, 로딩 중에 줄어든 HP는 화면이 밝아진 뒤에야 확인됩니다. 또 HP 바를 다른 프로그램 창이나 아콘 창이 가리면 HP를 정확히 읽을 수 없으니, 트레이 알림이 뜨면 창을 옮겨 주세요.

8-8. 버땅 · 그림자 신전 복귀 확인

언제 쓰나: 버림받은 자들의 땅에서 사냥하는데, 복귀 키순서가 가끔 실패해서 마을에 그냥 서 있는 일이 있을 때.

  • 스위치 이름은 버땅지역 복귀 확인 (버땅 전용)이고 기본은 꺼짐입니다.
  • 켜면 회복 후 키순서가 전부 끝난 뒤 3초 기다리고 사냥터 인식영역의 글자를 읽습니다.
  • 버림 / 받은 / 자들 중 하나라도 보이면 복귀 성공으로 보고 끝냅니다.
  • 하나도 안 보이면 회복 후 키순서를 다시 발동하고, 인식될 때까지 3초 간격으로 계속 반복합니다.
  • 이 대기 중에도 HP를 감시하므로, 귀환 임계값 미만이면 확인을 접고 다시 귀환합니다(8-7).
다른 사냥터에서 켜면 안 됩니다. 그 지역에는 위 문구가 없으므로 절대 인식되지 않고, 회복 후 키순서가 무한 반복되어 텔레포트 스크롤 같은 소모품을 계속 씁니다. 멈추는 방법은 ■ 중단뿐입니다.
그림자 신전에서 사냥한다면 바로 아래 그림자 신전 복귀 확인 (그림자 신전 전용) 스위치를 켜세요. 동작은 위와 같고, 그림자 / 신전 / 1층 / 2층 중 하나라도 보이면 복귀 성공입니다. 두 스위치는 둘 중 하나만 켜집니다(하나를 켜면 다른 하나는 자동으로 꺼짐). 그림자 신전 스위치를 켜 두면 텔레포트 지역 확인(8-9)도 그림자 신전 문구를 인정합니다.
사냥터 인식영역에는 기본값이 들어 있어 보통은 지정되어 있습니다. 값이 비어 있으면 이 확인은 건너뜁니다(켜도 아무 일 없음). 보통 화면 왼쪽 아래 지역명이 나오는 자리에 잡습니다.

8-9. 텔레포트 키순서 — 몬스터 미검출 시 / 무조건 텔

언제 쓰나: 주변 몬스터가 다 없어졌을 때, 또는 일정 시간마다 자리를 옮기고 싶을 때.

스위치기본발동 조건몬스터 인식 사용
몬스터 미검출 시꺼짐적용 시간 동안 몬스터가 한 마리도 안 보이면사용(그래픽카드를 씁니다)
무조건 텔꺼짐적용 시간마다 계속 반복사용 안 함
  • 적용 시간 — 기본 5초, 범위 1~120초.
  • 발동 키순서에 텔레포트 스크롤이나 순간이동을 넣습니다. 적용 시간과 발동 키순서 칸은 두 스위치 중 하나라도 켜야 입력할 수 있습니다.
  • 두 스위치는 둘 다 켤 수 있고, 각각 자기 시간을 따로 셉니다.
  • 사냥중 단계에서만 발동합니다. 마을 단계에서는 발동하지 않습니다.
  • 키순서가 비어 있으면 아무 일도 일어나지 않습니다.
지역 확인을 통과해야 발동합니다. 사냥터 인식영역의 글자에 타락 / 축복 / 땅의 / 버림 / 받은 / 자들 중 하나라도 있어야 키순서가 나갑니다. 영역 값이 비어 있거나 문구가 읽히지 않으면 그 차례는 보류됩니다(다른 지역에서의 오발동 방지). 보류된 차례는 시간을 다시 세지 않고 다음 차례에 또 확인합니다.
그래픽카드가 약한 PC라면 무조건 텔만 쓰세요. 몬스터 미검출 시는 켠 동안에만 몬스터 인식을 돌립니다.

8-10. ⏱ 타이머 키순서

언제 쓰나: 일정 시간마다 반복해야 하는 동작(주기적인 스킬, 소모품 사용 등)을 맡길 때.

⚙ 설정 창 왼쪽 아래 ⏱ 타이머 키순서 버튼으로 타이머 키순서 (ATS보조) 창을 엽니다.

  • 타이머 사용 — 전체 켜기/끄기 스위치, 기본 꺼짐. 이 스위치가 켜져 있고 ATS보조가 실행 중일 때만 동작합니다.
  • + 타이머 추가로 여러 개 등록할 수 있고, 각 칸마다 아래 항목이 있습니다.
    • 사용 — 이 타이머 하나만 끄고 켜기
    • 이름 — 구분용
    • 키순서 — 키순서 편집 버튼으로 반복 발동할 내용을 넣습니다. 비어 있으면 발동하지 않습니다.
    • 반복 간격 — 기본 60초, 범위 1~86400초
  • 첫 발동은 시작하자마자 즉시이고, 그 뒤로는 설정한 간격마다 반복합니다.
  • 사냥중 / 마을 단계와 무관하게 발동합니다.

자동사냥 탭의 ⏱ 타이머매크로와는 별개 목록입니다. 여기 등록한 것은 ATS보조 실행 중에만 돕니다.

8-11. 🎯 버프 관리

언제 쓰나: ATS보조로 감시만 돌리는 동안에도 버프가 끊기지 않게 하고 싶을 때. 🎯 버프 관리 버튼으로 ATS보조 버프 관리 창을 엽니다.

  • 자동사냥 버프와는 별개 목록입니다. 아래쪽 ⬇ 자동사냥 버프 가져오기로 자동사냥에 등록한 버프 중 필요한 것만 골라 복사할 수 있습니다(복사본이라 원본과 따로 관리됩니다).
  • + 버프 추가로 칸을 만듭니다. 버프 칸 하나에 들어가는 항목
    • 사용 · 이름 · 삭제
    • 아이콘 캡처 1 / 아이콘 캡처 2 — 버프 아이콘의 좌상단 → 우하단을 클릭해 아이콘 그림만 저장합니다. 2개 등록 가능하며 둘 중 하나라도 보이면 "버프 살아 있음"으로 봅니다(지역마다 배경색이 달라지는 경우 대비). 2번 삭제로 2번만 지울 수 있습니다.
    • 임계1 — 기본 0.50, 범위 0.10~0.99. 낮추면 관대, 높이면 엄격.
    • 임계2 — 같은 범위. 따로 건드리지 않으면 임계1과 같은 값을 씁니다. 2번 아이콘을 등록하지 않았으면 무시됩니다.
    • 키순서 — 버프가 사라졌을 때 다시 걸 내용
    • 검색영역 보기 · 매칭 테스트 — 아이콘을 찾는 범위와 지금 몇 점으로 읽히는지 즉시 확인
  • 아이콘을 찾는 검색영역은 기본값으로 정해져 있습니다(버프 아이콘이 표시되는 자리). 검색영역 보기로 위치만 확인하세요.
  • 확인 주기는 2초이고, 연속 3회 안 보여야 "사라짐"으로 확정합니다(순간 오인식 방지).
  • 같은 버프는 한 번 발동한 뒤 5초 안에는 다시 발동하지 않습니다.
  • 힐·귀환·복귀 키순서가 돌아가는 중에는 버프가 끼어들지 않고 그 차례를 건너뜁니다.
  • 아이콘이 하나도 등록되지 않았거나 키순서가 비어 있는 버프는 건너뜁니다. 아이콘 점수를 계산할 수 없는 회차도 발동하지 않고 넘어갑니다(오발동 방지).
MP 발동 조건 — 켜면 MP가 지정한 값 이상 또는 이하일 때만 그 버프를 발동합니다(0~100%, 기본 0%). MP를 읽지 못한 회차에는 이 조건을 따지지 않습니다.
타이머 — 켜면 아이콘을 보지 않고 시간만으로 반복 발동합니다. 기본 60초, 범위 1~3600초. 후발동(기본)은 설정 시간이 지나야 첫 발동, 선발동은 시작 즉시 첫 발동입니다. MP 발동 조건까지 켜 두었는데 조건이 맞지 않으면 1분 뒤에 다시 시도합니다.
버프 키순서가 발동되는 동안 ATS보조의 다른 동작은 잠깐 멈춥니다. 키순서를 길게 만들면 그만큼 힐 반응이 늦어집니다.

8-12. 🔍 아이템체크

언제 쓰나: 물약·화살·귀환 스크롤처럼 다 쓰면 칸이 비는 소모품을 지켜보다가, 비면 마을로 가거나 다른 칸을 쓰게 하고 싶을 때. 🔍 아이템체크 버튼으로 아이템체크 (ATS보조) 창을 엽니다.

  • + 아이템 추가로 여러 개 등록할 수 있습니다. 칸마다 들어가는 항목
    • 사용 · 이름 · 삭제
    • 슬롯 지정+캡처 — 게임 화면에서 그 아이템 칸의 좌상단 → 우하단을 클릭하면 그 즉시 화면을 저장합니다. 반드시 아이템이 그 칸에 들어 있는 상태에서 찍으세요.
    • 인식테스트 — 지금 있음인지 없음인지(또는 인식 실패인지) 바로 알려줍니다. 지정 직후 꼭 눌러 확인하세요.
    • 없을 때 키순서 — 아이템이 없어졌을 때 발동할 내용. 비어 있으면 발동하지 않습니다.
    • 키순서 후 마을 상태로 전환 (회복 대기 후 사냥터 자동 복귀) — 아래 설명
  • 확인 주기는 1초이며, 3초 연속 안 보일 때만 "없음"으로 확정해 키순서를 발동합니다. 창이 잠깐 가려 깜빡이는 정도로는 발동하지 않습니다.
  • 화면을 아예 못 읽은 회차는 판정을 보류합니다(있다/없다 어느 쪽으로도 세지 않음). 칸이 다른 프로그램 창에 가려져 있거나(브라우저로 전환 등) 텔레포트·귀환 로딩으로 화면이 새까만 동안에도 비어 보이는 것을 "없음"으로 세지 않고 보류하며, 다시 보이면 3초를 처음부터 셉니다. 보류가 30초 넘게 이어지면 보류를 풀고 평소대로 판단합니다.
  • 발동한 뒤에도 계속 없으면 10초마다 다시 발동합니다(귀환·구매 키순서가 겹쳐 나가지 않게). 단, 키순서 후 마을 상태로 전환을 켠 아이템은 마을에서 회복을 기다리는 동안에는 다시 발동하지 않고, 사냥터로 돌아간 뒤 처음부터 다시 셉니다(귀환 주문서 낭비 방지).
  • 귀환·힐·복귀 키순서가 돌아가는 중이면 그 차례는 건너뜁니다.
키순서 후 마을 상태로 전환이 하는 일 — 체크하면 위 키순서가 끝난 뒤 ATS보조가 "지금 마을에 있다"고 인식합니다. 그러면 평소 귀환과 똑같이 회복 대기(설정한 회복 %)를 거쳐 회복 후 키순서로 사냥터에 자동 복귀합니다. 키순서 안에 마을 귀환이 들어 있을 때만 켜세요. 끄면 키순서만 발동하고 끝납니다.
전환에 쓸 방식은 켜 둔 귀환 방식 중 회복 후 키순서가 채워진 것을 통합 → HP → MP 순으로 골라 씁니다. 켜 둔 방식의 회복 후 키순서가 전부 비어 있으면 전환하지 않습니다(돌아올 방법이 없어 마을에 갇히는 것을 막기 위함). 통합 귀환을 켰다면 HP·MP 회복 후 키순서, HP 귀환을 켰다면 HP 회복 후 키순서를 채워 두세요.
마나가 가득 찬 상태에서 소모품만 떨어지면 MP 귀환은 걸리지 않습니다. 이때 마을에 그냥 서 있는 것을 막아 주는 것이 바로 이 체크입니다.
인식 기준 점수와 "3초 연속" 조건은 화면에 노출되지 않는 고정값입니다. 게임 안의 창(상점·창고·지도 등)이 소모품 칸을 3초 넘게 덮으면 "없음"으로 볼 수 있으니, 사냥 중에는 칸이 보이게 두세요.

8-13. 🔧 자동손상수리 / 반자동 수리

언제 쓰나: 무기 손상을 숫돌로 알아서 수리하게 하고 싶을 때. 두 버튼 모두 ● 시작과 무관하게 따로 켜집니다.

먼저 준비할 것 — ⚙ 설정 오른쪽에서 아래 항목을 지정해야 합니다.

항목무엇을 잡나쓰는 기능
인벤토리 영역인벤토리가 열렸는지 판단할 영역자동손상수리만
숫돌 인식영역인벤 안에서 숫돌을 찾을 범위둘 다
손상도 인식손상 표시가 뜨는 자리둘 다
손상도 체크 무기 좌표수리할 무기 칸 (좌표 선택으로 한 점 지정)둘 다

🔧 자동손상수리 (반복) — 켜 두면 5초마다 아래를 반복합니다.

  • 인벤토리 영역에서 기준 모습을 찾으면 그 회차는 그냥 넘어갑니다. 찾지 못하면 Tab을 눌러 인벤토리를 열고 계속 진행합니다.

수리 중에는 인벤토리가 열리고 마우스가 실제로 움직이며 클릭합니다. 사람이 게임을 조작하는 중에 켜 두면 서로 방해가 됩니다. 🔧 자동손상수리는 끌 때까지 계속 반복하니, 수리가 끝나면 다시 눌러 꺼 주세요.
인벤 열기/닫기에 쓰는 키는 Tab으로 고정되어 있고, 숫돌·손상 표시를 알아보는 그림과 인식 기준 점수는 프로그램에 들어 있어 따로 캡처하지 않습니다. 자동사냥 탭에도 같은 수리 기능이 5분 주기로 따로 있습니다(🔧 자동손상수리).

8-15. restart / restart v2 — 죽음창 자동 처리

언제 쓰나: 캐릭터가 죽어 restart 창이 떴을 때 자동으로 눌러 주고, 이어서 정해 둔 키순서와 보급까지 진행하게 하고 싶을 때.

설정 칸은 ATS보조 ⚙ 설정 오른쪽 아래에 있지만, 실제 동작은 자동사냥이 돌고 있을 때 이루어집니다. ATS보조만 켜 둔 상태에서는 동작하지 않습니다.

restart (기본)

  • restart 이미지 → 이미지 캡처로 죽음창의 restart 버튼 좌상단 → 우하단을 클릭해 저장합니다. 저장되면 크기가 창 대비 몇 %인지 함께 표시되어, 창 크기가 달라도 맞춰 찾습니다. 이미지를 저장하지 않으면 감지 자체를 하지 않습니다.
  • restart 후 키순서 — 클릭이 성공한 뒤 발동할 내용(부활 위치 이동 등).
  • 동작 순서 — 10초마다 화면에서 그 이미지를 찾고, 찾으면 3초 뒤 그 위치를 클릭합니다. 창이 사라졌는지 확인하며 최대 5회까지 다시 클릭하고, 사라진 것이 확인되면 자동사냥을 끈 뒤 4초 뒤 restart 후 키순서를 발동합니다. 그 다음 5초 뒤 등록된 아이템 개수를 점검해 부족한 것만 목록에 담아 자동 보급으로 넘어갑니다(부족한 것이 없으면 창고 단계는 건너뜁니다).
  • 5회 클릭해도 창이 남아 있으면 키순서와 보급을 진행하지 않고 그대로 두었다가 10초 뒤 다시 확인합니다(잘못 인식했을 때의 피해를 막기 위함).

restart v2 — 위와 독립적으로 동작하는 보조 방식입니다.

  • restart v2 줄의 사용 스위치를 켭니다(기본 꺼짐).
  • 클릭 좌표 선택 — 감지되면 클릭할 위치. 기본값이 들어 있고 수정할 수 있으며 표기로 확인할 수 있습니다.
  • restart v2 이미지 → 이미지 캡처 — 죽음창이 떠 있는 상태에서 눌러야 합니다. 정해진 영역의 현재 화면을 그대로 저장합니다.
  • 10초마다 그 영역만 비교해 맞으면 지정 좌표를 빠르게 10번 클릭합니다.
  • 사용 스위치·클릭 좌표·이미지 3가지가 모두 준비돼야 동작합니다.
restart v2 이미지는 PC(해상도)마다 한 번씩 새로 캡처해야 합니다. 죽음창이 없는 평소 화면을 캡처하면 영원히 감지되지 않거나, 반대로 멀쩡한 화면에서 좌표를 계속 클릭하게 됩니다.

9. 웹 원격 제어 — 휴대폰으로 조작

9-1. 어떤 기능인가

언제 쓰나: PC를 켜 둔 채 자리를 비웠을 때, 휴대폰으로 자동사냥을 시작·중단하거나 지금 게임 화면이 어떤 상태인지 확인하고 싶을 때.

  • 휴대폰 브라우저로 https://archon-macro.com/remote/ 에 들어가 아콘이 발급한 원격 코드만 입력하면 연결됩니다. 휴대폰에 따로 설치할 것도, 공유기·방화벽 설정도 없습니다.
  • 연결되면 PC 아콘의 상태(자동사냥·보급·길찾기·ATS보조 작동 여부와 HP/MP)가 휴대폰에 2.5초마다 갱신되고, 버튼을 누르면 PC의 아콘이 그 명령을 받아 실행합니다.
  • PC 쪽 준비물은 두 가지입니다 — 아콘이 실행 중일 것, 그리고 웹 원격 제어 사용이 켜져 있을 것.
  • 휴대폰에서 쓸 수 있는 것은 자동사냥 카드, ATS보조 카드, 게임 화면(1장 캡쳐), 키 전송(F1~F12) 네 가지입니다.
아콘을 켤 때 웹 원격 제어 사용이 켜져 있고 코드가 발급돼 있으면 원격 연결은 자동으로 준비됩니다. 아콘을 실행할 때마다 따로 켜 줄 필요는 없습니다.
원격 제어는 PC가 켜져 있고 아콘이 실행 중일 때만 동작합니다. PC가 꺼지거나 아콘이 종료되면 휴대폰에는 응답 없음 또는 ⚠ 오프라인으로 표시되고 자동사냥·ATS보조 버튼이 잠깁니다.

9-2. PC에서 켜기 — 원격 코드 발급

언제 쓰나: 처음 한 번, 휴대폰에서 쓸 코드를 만들 때.

  • 어디서 여나 — 자동사냥 설정 창 아래쪽 버튼 줄의 🌐 웹 원격 제어, 또는 자동쫄법사 설정 창의 📡 통신 진단 옆에 있는 🌐 웹 원격 제어입니다. 어느 쪽에서 열어도 같은 창이며 설정도 하나로 공유됩니다.
  • ① 웹 원격 제어 사용을 켭니다. (기본값 꺼짐)
  • ② 저장을 누릅니다. 코드가 없던 상태라면 이때 원격 코드가 자동으로 만들어집니다. 켜기 전에는 코드 자리에 (사용 저장 시 자동 생성)이라고만 표시됩니다.
  • ③ 저장하면 창이 닫히므로, 창을 다시 열어 노란 글씨로 표시된 원격 코드를 확인하고 휴대폰에 그대로 입력합니다.

원격 코드는 영문 대문자와 숫자 8자리입니다. 눈으로 헷갈리기 쉬운 0 · O · 1 · I 는 아예 쓰지 않으므로, 보이는 대로 입력하면 됩니다.

원격 코드는 이 코드만 알면 누구나 조작할 수 있는 열쇠입니다. 화면 공유·방송 화면에 코드가 노출되지 않게 하시고, 노출됐다면 9-4의 코드 재발급으로 즉시 바꾸세요.
끄고 싶을 때는 웹 원격 제어 사용을 끄고 저장을 누르면 됩니다. 그 즉시 PC가 명령 받기를 멈춥니다. 코드 자체는 지워지지 않으므로, 다시 켜고 저장하면 같은 코드로 이어서 쓸 수 있습니다.

9-3. 휴대폰에서 연결하기

언제 쓰나: 발급받은 코드로 휴대폰을 PC에 붙일 때.

  • 휴대폰 브라우저에서 https://archon-macro.com/remote/ 를 엽니다.
  • 원격 코드 입력칸에 코드를 넣고 연결을 누릅니다. 소문자로 입력해도 자동으로 대문자로 바뀝니다.
  • 연결되면 코드 입력칸이 사라지고 제어판이 나타납니다. 코드는 그 휴대폰에 기억되어, 다음에 페이지를 다시 열면 자동으로 연결됩니다.
  • 기억된 코드를 지우려면 상태 카드 오른쪽의 해제를 누르세요. 다시 코드 입력 화면으로 돌아갑니다.
브라우저의 홈 화면에 추가로 바로가기를 만들어 두면 앱처럼 한 번에 열립니다. 코드가 기억돼 있으니 열기만 하면 바로 제어판이 뜹니다.
한 대의 PC에 휴대폰 여러 대를 붙일 수도 있습니다. 같은 코드를 입력하면 모두 같은 PC를 조작합니다. 그래서 코드 관리가 곧 보안입니다.

9-4. 코드 재발급 — 저장을 눌러야 확정됩니다

언제 쓰나: 코드가 남에게 노출됐을 때, 또는 쓰던 코드를 새 것으로 바꾸고 싶을 때.

  • 🌐 웹 원격 제어 창에서 코드 재발급을 누르면 화면의 코드가 새 코드로 바뀝니다.
  • 이 시점에는 아직 바뀐 것이 아닙니다. 저장을 눌러야 새 코드가 확정됩니다.
  • 재발급을 눌렀다가 취소로 창을 닫으면 예전 코드가 그대로 유지됩니다. 화면에 잠깐 보였던 새 코드는 버려집니다.
새 코드를 저장하면 예전 코드는 즉시 못 쓰게 됩니다. 예전 코드를 기억하고 있던 휴대폰은 응답 없음으로 표시되므로, 휴대폰에서 해제를 누르고 새 코드로 다시 연결해야 합니다.
저장 직후에는 PC가 새 코드로 갈아타는 데 최대 6초가 걸립니다. 휴대폰이 잠깐 응답 없음이나 ⚠ 오프라인으로 보이더라도 몇 초 기다리면 정상으로 바뀝니다.

9-5. 휴대폰 화면 읽는 법 — 상태 · HP/MP

언제 쓰나: 지금 PC에서 무엇이 돌고 있는지 확인할 때.

표시뜻

빨간 점 + 상태 글씨 앞에 ⚠ 오프라인 ·마지막 상태가 15초 이상 지난 경우입니다. PC가 꺼졌거나 아콘이 종료됐거나 인터넷이 끊긴 상태입니다. 이때 자동사냥·ATS보조 버튼이 모두 잠깁니다.
응답 없음그 코드로 올라온 상태가 아예 없는 경우, 또는 휴대폰이 상태를 받아오지 못한 경우입니다. 코드가 틀렸거나, PC에서 웹 원격 제어 사용이 꺼져 있을 때 이렇게 보입니다.

명령이 무시될 때 휴대폰에는 따로 안내가 뜨지 않습니다. 버튼을 누르면 화면 아래에 전송 안내만 잠깐 뜨므로, 상태 글씨와 HP/MP가 바뀌는지로 성공 여부를 판단하세요. 몇 초 기다려도 상태가 그대로면 거부된 것입니다 (9-12 참고). 휴대폰 인터넷이 끊겨 전송 자체가 실패하면 전송 실패 (네트워크)가 뜹니다.

9-7. 게임 화면 보기

언제 쓰나: 밖에서 "지금 잘 사냥하고 있나, 죽어 있나"를 눈으로 확인할 때.

  • 📷 화면 보기 (1장 캡쳐)를 누르면 캡쳐 요청 중…이 표시되고, PC가 게임창을 한 장 찍어 올려 주면 잠시 뒤 휴대폰에 사진이 나타납니다. 사진 아래에는 캡쳐 ○○:○○:○○으로 받은 시각이 표시됩니다.
  • 사진은 가로 최대 640픽셀로 줄여서 보냅니다. 데이터 사용량을 줄이기 위한 것이라 글씨가 작게 보일 수 있습니다.
  • 사진을 탭하면 크게 볼 수 있고, 크게 본 상태에서 한 번 더 탭하면 더 확대돼 좌우로 밀어 볼 수 있습니다. ✕ 또는 배경을 탭하면 닫힙니다.
  • 버튼은 누른 뒤 10초 동안 잠깁니다. 남은 시간이 📷 대기 ○초로 버튼에 표시됩니다.
  • 사진이 약 10초 안에 오지 않으면 응답 없음 (아콘 실행/원격 켜짐 확인)으로 바뀝니다. 아콘 실행 여부와 웹 원격 제어 사용을 확인한 뒤 다시 시도하세요.
동영상이 아니라 누를 때마다 한 장입니다. 계속 지켜보려면 10초 간격으로 다시 눌러야 합니다.
대상 게임창이 등록돼 있지 않거나 게임창이 닫혀 있으면 찍을 화면이 없습니다. 외출 전에 대상 게임창 등록을 확인하세요.

9-8. F1 ~ F12 키 전송

언제 쓰나: 밖에서 물약·귀환 스크롤·버프처럼 F키에 걸어 둔 동작을 한 번 눌러 주고 싶을 때.

  • 보낼 수 있는 키는 F1부터 F12까지 12개뿐입니다. 다른 키나 마우스 클릭은 웹에서 보낼 수 없습니다.
  • 키를 보내면 PC가 대상 게임창을 먼저 앞으로 띄운 뒤 그 키를 한 번 누릅니다. 아콘이 평소 게임에 입력을 넣는 것과 같은 방식으로 눌립니다.
  • 대상 게임창이 등록돼 있지 않거나 찾지 못하면 창을 앞으로 띄우지 않고 키만 눌립니다. 이때는 그 순간 앞에 있던 창이 키를 받게 됩니다.
  • 버튼마다 누른 뒤 1초 동안 잠깁니다. 빠르게 연타되는 것을 막기 위한 제한입니다.
키를 보내면 게임창이 맨 앞으로 올라옵니다. PC에서 다른 작업을 하고 있는 사람이 있다면 그 창이 뒤로 밀립니다. 또 게임창이 최소화돼 있던 경우에도 복원되어 앞으로 나옵니다.
키가 눌렸는지 알려 주는 표시는 없습니다. 결과가 궁금하면 📷 화면 보기 (1장 캡쳐)로 확인하세요. 이 버튼과 F키 버튼은 ⚠ 오프라인 상태에서도 잠기지 않으므로, 눌렸는지 여부는 상태 글씨로 판단하셔야 합니다.

9-9. 권한에 따라 달라지는 것

언제 쓰나: 휴대폰에 카드가 안 보이거나, 눌러도 아무 일도 안 일어날 때.

  • ATS보조 카드는 자동사냥 이용 권한이 있는 계정에서만 보입니다. 권한이 없으면 카드 자체가 화면에 나타나지 않습니다.
  • 자동사냥 카드는 항상 보입니다. 권한이 없는 계정에서 ▶ 시작을 눌러도 아콘이 거부하므로 상태가 변하지 않습니다.
  • 카드가 보이더라도 최종 판단은 PC의 아콘이 합니다. 권한이 없으면 아콘이 명령을 그대로 거부하고, 휴대폰의 상태는 ⚫ 대기에서 바뀌지 않습니다.
즉 휴대폰 화면에서 카드를 숨기는 것은 보기 편하게 하려는 것일 뿐이고, 실제 차단은 언제나 PC의 아콘에서 이루어집니다.

9-10. 확인창이 뜨지 않습니다 — 외출 전 점검

언제 쓰나: 원격으로 켜고 끌 생각으로 PC를 두고 나가기 전에.

  • 원격으로 들어온 명령은 "정말 시작할까요?" 같은 확인창 없이 바로 실행됩니다. PC 앞에 사람이 없는데 확인창이 떠 버리면 아무도 닫을 수 없어 아콘 전체가 멈추기 때문입니다.
  • 같은 이유로, 권한이 없어 거부되는 경우에도 PC에 안내창을 띄우지 않고 조용히 거부합니다.
  • 따라서 누르면 바로 실행된다고 생각하고 쓰셔야 합니다. 실수로 ■ 중단을 누르면 그대로 사냥이 멈춥니다.
모든 경고창이 사라지는 것은 아닙니다. 자동사냥 ▶ 시작과 🚚 이동 후 사냥은 대상 게임창이 등록되지 않았거나 시작에 필요한 준비가 안 된 경우 PC 화면에 경고창을 띄우고 그 자리에 멈춰 버립니다. 곁에 사람이 없으면 그 창을 닫을 수 없어 이후 원격 조작도 듣지 않습니다.
외출 전 점검 — ① PC에서 자동사냥을 한 번 정상 시작·중단해 보기 ② 대상 게임창 등록 확인 ③ 이동 후 사냥을 쓸 거면 창고 OK 후 사냥터 이동 키순서와 길찾기 목표 좌표·최하단 텍스트인식영역 확인 ④ HP/MP를 보려면 HP 게이지·MP 게이지 인식영역 지정 확인 ⑤ 휴대폰에서 연결해 점이 초록으로 뜨는지, 📷 화면 보기 (1장 캡쳐)가 되는지 확인. 여기까지 되면 밖에서도 그대로 동작합니다.
PC 앞에 있는 동안에는 Insert로도 자동사냥을 시작·중단할 수 있습니다. 원격과 어느 쪽을 써도 같은 기능입니다.

9-11. 반응 속도와 데이터 사용량

언제 쓰나: "눌렀는데 왜 조금 늦게 되나" 싶을 때, 데이터가 걱정될 때.

  • PC는 평소 2초마다 새 명령이 있는지 확인합니다. 그래서 버튼을 누르면 보통 2초 안에 실행됩니다.
  • 명령을 한 번 받으면 이후 25초 동안은 0.3초 간격으로 빠르게 확인합니다. 그래서 연속으로 조작할 때는 거의 즉시 반응합니다. F키를 여러 번 누를 때 특히 체감됩니다.
  • 웹페이지를 열어 둔 동안에는 15초마다 신호를 보내 이 빠른 반응 상태를 유지합니다. 즉 휴대폰 페이지를 열어 두면 계속 빠르게 반응합니다.
  • PC는 상태를 2초마다 올리고, 휴대폰은 2.5초마다 받아옵니다. 주고받는 상태 정보는 아주 짧은 글자라 데이터를 거의 쓰지 않습니다.
  • 데이터를 실제로 쓰는 것은 화면 보기뿐입니다. 요청할 때만 사진 1장(수십 KB 정도)을 받습니다.
휴대폰 화면을 끄거나 다른 앱으로 넘어가면 갱신이 멈췄다가, 페이지로 돌아오는 순간 즉시 다시 갱신됩니다. 돌아왔을 때 ⚠ 오프라인으로 보이더라도 1~2초 기다려 보세요.

9-12. 잘 안 될 때 점검 순서

증상확인할 것
코드를 넣었는데 응답 없음① PC에서 아콘이 실행 중인지 ② 웹 원격 제어 사용이 켜져 있고 저장까지 눌렀는지 ③ 휴대폰에 넣은 코드가 지금 창에 보이는 코드와 같은지(재발급 후 옛 코드를 쓰고 있지 않은지) ④ PC와 휴대폰이 인터넷에 연결돼 있는지.
상태 글씨 앞에 ⚠ 오프라인 · 이 붙음PC가 절전·종료됐거나 아콘이 닫혔거나 인터넷이 끊긴 경우입니다. 최근 갱신 시간이 계속 커지면 PC 쪽 문제입니다.
재발급 후 연결이 안 됨휴대폰이 옛 코드를 기억하고 있습니다. 해제를 누르고 새 코드로 다시 연결하세요. 저장 직후 최대 6초는 기다려야 합니다.
버튼이 회색으로 눌리지 않음대부분 정상입니다 — 오프라인이거나, 이미 작동 중이거나, ATS보조가 돌고 있어 자동사냥 버튼이 잠긴 경우, 또는 방금 누른 버튼이 약 6초 잠긴 경우입니다.
▶ 시작을 눌렀는데 상태가 ⚫ 대기 그대로① 해당 기능 권한이 없어 거부됐거나 ② PC 화면에 경고창이 떠 멈춘 경우입니다. 📷 화면 보기 (1장 캡쳐)로 PC 상황을 확인해 보세요.
🚚 이동 후 사냥이 듣지 않음아이템 관리의 창고 OK 후 사냥터 이동 키순서가 비어 있으면 아콘이 아예 실행하지 않습니다. 자동사냥·보급·길찾기가 이미 진행 중일 때도 무시됩니다. 대상 게임창이 등록돼 있지 않으면 PC에 경고창이 떠 멈춥니다.
🚚 이동 후 사냥이 이동을 건너뜀자동사냥 설정의 목표 좌표나 ATS보조 설정의 최하단 텍스트인식영역이 없으면 길찾기를 건너뛰고 그 자리에서 자동사냥을 시작합니다.
HP / MP가 — 로만 표시대상 게임창을 찾지 못한 경우이거나, ATS보조 탭 📍 인식영역 설정의 HP 게이지·MP 게이지를 아직 지정하지 않은 경우입니다.
화면 보기가 게임창을 찾을 수 없음대상 게임창이 닫혔거나 등록돼 있지 않은 상태입니다.
화면 보기가 응답 없음 (아콘 실행/원격 켜짐 확인)사진이 제때 올라오지 않은 경우입니다. 아콘 실행과 웹 원격 제어 사용을 확인한 뒤, 10초 대기가 끝나면 다시 누르세요.
F키를 눌렀는데 게임에 반응이 없음게임창이 앞으로 나오는지 📷 화면 보기 (1장 캡쳐)로 확인하세요. 대상 게임창이 등록돼 있어야 하고, 아콘이 게임에 입력을 넣을 수 있는 상태(PC에서 평소 매크로가 정상 동작하는 상태)여야 합니다.
버튼을 누르면 전송 실패 (네트워크)휴대폰의 인터넷 연결 문제입니다. 명령이 PC로 가지 않았으니 연결을 확인하고 다시 누르세요.

10. 기타 참고 사항

증상원인과 해결
HP 키순서가 안 나감키순서가 비어 있음. 또는 "HP 미만일 때만 발동" 토글이 켜진 상태에서 MP만 부족한 경우.
귀환 후 버프가 풀림귀환 키순서에 넣은 버프가 이후 회복 키 입력으로 풀리는 경우 — "HP 회복 후 보급" 체크를 해제하면 귀환 키만 입력합니다.
몹 미검출 귀환이 안 됨"귀환 후 자동 보급" 토글이 꺼져 있거나, 몹 미검출 시간이 0으로 설정되어 있음.
보급 후 사냥이 재개 안 됨길찾기 1차 목표 좌표 또는 최하단 텍스트 인식영역이 미설정 — 보급 사이클은 길찾기로 복귀하므로 둘 다 필수입니다.
인출 수량이 이상함"창고에서 찾을 개수"는 보유 목표량입니다 — 인출은 부족분(목표량 − 현재 보유량)만 입력됩니다.
버프를 계속 다시 검임계가 너무 높아 걸린 버프를 "없다"고 판정 — 매칭 테스트로 점수 확인 후 임계를 낮추거나, 배경이 다른 지역이라면 템플릿2를 추가.
버프를 아예 안 검임계가 너무 낮아 배경만 보고 "있다"고 판정 — "매칭 테스트"로 점수를 확인하고 임계를 올리세요. 타이머를 켰다면 아이콘 감지는 원래 생략됩니다.
제자리에서 같은 곳만 공격원거리 모드에서 시야 가림 — "나무가림방지"를 켜고 대기 초를 몹 하나 잡는 시간보다 길게. 뉴 원거리 v2·제자리 원거리는 같은 몹이 20초(가까운 몹 45초) 안 죽으면 자동으로 다른 몹으로 넘어갑니다.
길찾기가 맴돌기만 함도착 판정 거리가 너무 작음(10셀 권장) 또는 좌표 텍스트 인식영역이 잘못 지정됨.
몬스터 인식이 느림상단 상태줄이 CPU로 표시되는 경우 — 그래픽 드라이버/Windows 업데이트 후 재시작.
