자주 묻는 질문 (FAQ)

게임창 설정 관련
게임창 해상도(크기)는 얼마로 설정해야 하나요? ▼
게임창의 해상도(크기)는 최소 1280×960 이상을 유지해야 인식에 어려움이 없습니다.
그 이하로 줄이면 HP/MP 게이지, 텍스트 인식, 템플릿 매칭 정확도가 크게 떨어질 수 있습니다.

※ 좌표를 새로 지정한 후 게임창 크기를 변경하면 비율이 어긋날 수 있으니, 주로 사용할 크기로 고정한 다음 좌표를 지정하는 것을 권장합니다.
설치 관련
설치 파일 실행 시 파란색 보안 경고 창이 뜹니다. ▼
Windows SmartScreen 보안 경고로, 정상적인 동작입니다.

Archon Macro는 코드사이닝 인증서(OV)로 서명되어 있어 게시자가 "biniheart"로 표시됩니다.
이는 프로그램의 안전성이 검증되었다는 의미입니다.

해결 방법:
1. 파란색 경고 창에서 "추가 정보"를 클릭합니다.
2. 게시자가 "biniheart"인지 확인합니다.
3. "실행" 버튼을 클릭합니다.

※ 이 경고는 새로운 프로그램에 일시적으로 표시되며, 사용자가 늘어나면 자동으로 사라집니다.
USB 장치를 연결했는데 인식이 안 됩니다. ▼
다른 USB 포트에 연결해 보세요. USB 허브가 아닌 PC 본체에 직접 연결하는 것을 권장합니다.
그래도 안 되면 PC를 재부팅한 후 다시 연결해 주세요.
설치 후 실행하면 "장치를 찾을 수 없습니다" 오류가 뜹니다. ▼
USB 장치가 연결되어 있는지 확인하세요. 프로그램 실행 전에 USB 장치를 먼저 연결해야 합니다.
이미 연결되어 있다면 USB를 뽑았다가 다시 연결한 후 프로그램을 재실행하세요.
"기존 사용 포트가 있습니다" 오류가 뜹니다. ▼
프로그램이 이미 실행 중이거나 이전에 정상 종료되지 않은 경우 발생합니다.
작업 관리자에서 Archon Macro를 종료한 후 다시 실행하세요.
관리자 권한 요청 팝업이 뜨는데 괜찮은 건가요? ▼
네, 정상입니다. Archon Macro는 키보드/마우스 입력을 제어하기 위해 관리자 권한이 필요합니다.
'예'를 클릭하여 실행해 주세요.
사용 관련
단축키를 눌러도 매크로가 동작하지 않습니다. ▼
다음 사항을 확인해 주세요:
1. 상태바의 체크박스가 초록색(활성)인지 확인
2. 해당 슬롯이 '비활성' 상태가 아닌지 확인 (클릭하여 활성화)
3. 대상 창이 설정되어 있다면 해당 창이 활성화되어 있는지 확인
4. ESC를 3초 이상 눌러 전체 비활성화된 상태가 아닌지 확인
게임에서 키 입력이 안 됩니다. ▼
게임이 관리자 권한으로 실행 중일 수 있습니다. Archon Macro도 관리자 권한으로 실행되어야 합니다.
프로그램을 종료하고 우클릭 → '관리자 권한으로 실행'을 선택하세요.
마우스 클릭 좌표가 정확하지 않습니다. ▼
대상 창을 설정하면 창 기준 상대좌표로 저장됩니다. 창이 이동하더라도 정확한 위치에 클릭됩니다.
대상 창이 설정되지 않은 경우 화면 절대좌표로 동작하므로, 모니터 해상도가 변경되면 재설정이 필요합니다.
한글 타이핑이 깨져서 나옵니다. ▼
PC의 입력 모드가 한글로 설정되어 있는지 확인하세요.
한글 타이핑은 두벌식 자모 분해 방식으로 입력되므로, 반드시 한글 입력 모드여야 합니다.
슬롯을 일시적으로 끄고 싶습니다. ▼
상태바에서 해당 매크로 버튼을 클릭하면 비활성화됩니다. 다시 클릭하면 활성화됩니다.
전체를 끄려면 체크박스를 클릭하거나 ESC를 3초 이상 누르세요.
자동사냥을 빠르게 켜고 끄고 싶습니다. ▼
ScrollLock 키를 누르면 자동사냥이 ON/OFF 토글됩니다. 게임 화면에서 바로 시작/중단할 수 있습니다.
'단축키 입력 차단' 기능은 무엇인가요? ▼
단축키로 설정한 키가 게임이나 프로그램에 전달되지 않도록 차단하는 기능입니다.
예를 들어 Tab을 단축키로 사용하면, Tab을 눌러도 게임에서 아이템창이 열리지 않고 매크로만 실행됩니다.
설정 관련
설정을 다른 PC에 옮기고 싶습니다. ▼
설치 폴더의 macro_config.json 파일을 복사하면 됩니다.
기본 경로: C:\Program Files (x86)\Archon Macro\macro_config.json
대상 창은 어떻게 설정하나요? ▼
설정 창 상단의 '창 선택' 버튼을 클릭한 후 3초 안에 대상 프로그램 창을 클릭하세요.
최대 2개 창까지 설정할 수 있습니다.
설정을 변경했는데 적용이 안 됩니다. ▼
설정 변경 후 반드시 '저장' 버튼을 눌러야 적용됩니다.
저장하지 않고 창을 닫으면 변경사항이 취소됩니다.
